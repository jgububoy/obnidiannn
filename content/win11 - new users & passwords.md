# win11 - new users & passwords problems

ძალიან კარგი შეკითხვაა! **Windows 11** -ში ახალი მომხმარებლის (User Account) შექმნა და პაროლის დადება ოდნავ შეიცვალა წინა ვერსიებთან შედარებით, რადგან Microsoft-ი აქტიურად გვთავაზობს Microsoft Account-ის გამოყენებას.

აქ მოცემულია, თუ როგორ უნდა შექმნათ **ლოკალური მომხმარებლის ანგარიში** (Local User Account) პაროლით:
## new users

### 1. 👥 ახალი მომხმარებლის დამატება

#### ნაბიჯი 1: პარამეტრების გახსნა

1. გახსენით **Settings** (პარამეტრები). შეგიძლიათ დააჭიროთ $\text{Win} + \text{I}$ კლავიშებს.
2. მარცხენა მენიუში აირჩიეთ **Accounts** (ანგარიშები).
3. აირჩიეთ **Other users** (სხვა მომხმარებლები) ან **Family & other users** (ოჯახი და სხვა მომხმარებლები).

#### ნაბიჯი 2: ახალი მომხმარებლის დამატება

1. **Other users** განყოფილებაში დააწკაპუნეთ **Add account** (ანგარიშის დამატება) ღილაკზე.
2. გამოჩნდება ფანჯარა, რომელიც გთხოვთ Microsoft-ის მონაცემების შეყვანას. ამის თავიდან ასაცილებლად, დააწკაპუნეთ ბმულზე:
    - **I don't have this person's sign-in information** (მე არ მაქვს ამ პირის შესვლის ინფორმაცია).
3. შემდეგ გვერდზე, კვლავ აირჩიეთ ბმული:
    - **Add a user without a Microsoft account** (მომხმარებლის დამატება Microsoft-ის ანგარიშის გარეშე).


#### ნაბიჯი 3: მომხმარებლის შექმნა და პაროლის დადება

1. შეიყვანეთ ახალი **User name** (მომხმარებლის სახელი), მაგალითად, "სტუმარი" ან "ადგილობრივი მომხმარებელი".
2. შეიყვანეთ **Password** (პაროლი) და დაადასტურეთ იგი.
3. უსაფრთხოების მიზნით, შეავსეთ სამივე **Security questions** (უსაფრთხოების შეკითხვა).
4. დააწკაპუნეთ **Next** (შემდეგი).

ახალი ადგილობრივი მომხმარებელი შექმნილია პაროლით.

---

### 2. 🔑 არსებულ ანგარიშზე პაროლის დადება ან შეცვლა

თუ გსურთ, რომ უკვე არსებულ ადგილობრივ ანგარიშზე დაადოთ ან შეუცვალოთ პაროლი:

1. გახსენით **Settings** ($\text{Win} + \text{I}$) $\rightarrow$ **Accounts** (ანგარიშები).
2. აირჩიეთ **Sign-in options** (შესვლის პარამეტრები).
3. **Password** (პაროლი) განყოფილებაში დააწკაპუნეთ **Add** (დამატება) (თუ პაროლი არ გაქვთ) ან **Change** (შეცვლა) (თუ პაროლი გაქვთ).
4. მიჰყევით ინსტრუქციებს ახალი პაროლის დასაყენებლად.

---

### 3. ⭐ ანგარიშის ტიპის შეცვლა (Standard vs. Administrator)

თუ გსურთ, რომ შექმნილ ახალ მომხმარებელს ადმინისტრატორის უფლებები ჰქონდეს:

1. გახსენით **Settings** $\rightarrow$ **Accounts** $\rightarrow$ **Other users**.
2. დააწკაპუნეთ თქვენს მიერ შექმნილ ახალ მომხმარებელზე.
3. დააწკაპუნეთ **Change account type** (ანგარიშის ტიპის შეცვლა).
4. **Account type** (ანგარიშის ტიპი) ჩამოსაშლელი მენიუდან აირჩიეთ **Administrator** (ადმინისტრატორი).
5. დააჭირეთ **OK**.


## win11 -ში პაროლს ვერ ვაყენებ, არ არის password გრაფა

თუ "**Sign-in options**" (შესვლის პარამეტრები) განყოფილებაში **საერთოდ არ ჩანს "Password" (პაროლი) გრაფა**, სავარაუდოდ, თქვენი სისტემა კონფიგურირებულია ისე, რომ აუცილებლად მოითხოვოს **Windows Hello**-ს გამოყენება.

აქ არის ორი ძირითადი მიზეზი, თუ რატომ შეიძლება არ ჩანდეს პაროლის ვარიანტი და როგორ უნდა მოაგვაროთ ეს:

### 1. Windows Hello-სთვის სავალდებულო შესვლის გამორთვა

თქვენი Windows 11 სისტემა შეიძლება დაყენებული იყოს იმისთვის, რომ ყველა მომხმარებელმა გამოიყენოს Windows Hello-ს მეთოდი (PIN, თითის ანაბეჭდი ან სახის ამოცნობა). ამის შესაცვლელად:


1. **გახსენით "Settings" (პარამეტრები).**
2. **გადადით "Accounts" (ანგარიშები).**
3. **აირჩიეთ "Sign-in options" (შესვლის პარამეტრები).**
4. გადადით განყოფილებაში **"Additional settings" (დამატებითი პარამეტრები)**.
5. იპოვეთ პარამეტრი სახელწოდებით:
	1. **"For improved security, only allow Windows Hello sign-in for Microsoft accounts on this device (Recommended)."** (ქართულად: "გაუმჯობესებული უსაფრთხოებისთვის, ამ მოწყობილობაზე Microsoft-ის ანგარიშებისთვის დაუშვით მხოლოდ Windows Hello-თ შესვლა (რეკომენდებული).")
6. **გამორთეთ (Turn Off) ეს ფუნქცია.** (გადაიტანეთ ღილაკი **Off** პოზიციაში).
    

ამ ნაბიჯის შესრულების შემდეგ, "Sign-in options" გვერდი უნდა განახლდეს და **"Password" (პაროლი)** გრაფა **"Add" (დამატება)** ღილაკით უნდა გამოჩნდეს.

### 2. PIN-ის დროებით წაშლა (თუ ზედა მეთოდი არ მუშაობს)

ზოგჯერ, სანამ სისტემაში არის აქტიური PIN, ის არ გაძლევთ საშუალებას დაამატოთ ჩვეულებრივი პაროლი. თუ ზემოთ მოყვანილი პარამეტრის გამორთვამ არ უშველა:

1. **გახსენით "Sign-in options" (შესვლის პარამეტრები).**
2. **დააჭირეთ "Windows Hello PIN".**
3. უნდა გამოჩნდეს ღილაკი **"Remove" (წაშლა)**. დააჭირეთ მას.
4. სისტემა მოგთხოვთ დაადასტუროთ თქვენი Microsoft ანგარიშის პაროლი (რომელიც გამოიყენეთ კომპიუტერის თავდაპირველად ასამუშავებლად).
5. PIN-ის წაშლის შემდეგ, ავტომატურად უნდა გამოჩნდეს **"Password" (პაროლი)** განყოფილება **"Add" (დამატება)** ღილაკით, რათა დააყენოთ სასურველი პაროლი.

**შენიშვნა:** თუ ამ ნაბიჯებს მიჰყვებით, თქვენი შესვლის მეთოდი დაუბრუნდება ძველ, ტრადიციულ პაროლს (რომელსაც ახლა დააყენებთ).
