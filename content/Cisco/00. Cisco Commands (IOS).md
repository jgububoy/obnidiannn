# Cisco (IOS) ძირითადი ბრძანებები

Cisco-ს ძირითადი ბრძანებები მოიცავს: **enable** — პრივილეგირებული რეჟიმისთვის, **configure terminal** — გლობალური კონფიგურაციისთვის, **interface <ტიპი/ნომერი>** — ინტერფეისის პარამეტრებისთვის და **show** ბრძანებები — შემოწმებისთვის. მართვის საფუძველია **copy running-config startup-config** ან მოკლე ბრძანება **wr** კონფიგურაციის შესანახად.

#### ფუნდამენტური  რეჟიმები და წვდომა 

1. `Router>` ***enable***  ( პრივილეგირებულ **EXEC** რეჟიმში შესვლა ).
2. `Router#` ***disable***  ( მომხმარებლის **EXEC** რეჟიმში დაბრუნება ).
3. `Router#` ***configure terminal***  ( ან შემოკლებით: ***conf t*** )  . ( **გლობალური** კონფიგურაციის რეჟიმში. )
4. `Router(config)#` ***interface fastEthernet 0/0***  ( **interface mode** - ში გადასვლა)
5. `Router(config-if)#` ***ip address "ip მისამართი" "maska"*** - - -  ( ასე გაუწერ ip მისამართს ).
6. `Router(config)#` ***line console 0*** - - - ( **console port**-ის ნომერ "**0**" -ინტერფეისის კონფიგურაცია. და **line mode**-ში გადასვლა )
7. `Router(config-line)#` 
8. 
9. `exit` : ერთი საფეხურით უკან დაბრუნება.
10. `end` : პრივილეგირებულ **EXEC** რეჟიმში პირდაპირ დაბრუნება.


#### ინტერფეისის კონფიგურაცია

- `Router# interface <type/number>`: (მაგ: ***interface fastEthernet 0/0*** ) კონკრეტული ინტერფეისის კონფიგურაციის რეჟიმში შესვლა.
- `Router# int fa 0/0` - - - ზედა **შემოკლებით** ასე ჩაიწერება. 
- **`Router(config-if)# ip address <ip> <mask>`**: IP მისამართისა და ქვექსელის ნიღბის (mask) მინიჭება.
- **`no shutdown`**: ინტერფეისის ჩართვა (აქტივაცია).
- **`shutdown`**: ინტერფეისის გამორთვა.
- **`description <text>`**: ინტერფეისისთვის აღწერილობის დამატება (იდენტიფიკაციისთვის).
- `R1# erase startup-config` - - - მოწყობილობის ***დარესეტება***. [switch && Router reset](switch%20&&%20Router%20reset.md)  
- `R1(config)# no ip domain-lookup ` - - - ***DNS ძიების გათიშვა*** ( არასწორად აკრეფილი **ბრძანებების იგნორირება** ).

#### ინფორმაციის დათვალიერება (Show ბრძანებები)

- Cisco-ს მოწყობილობებზე **სტატუსების ნახვა, დიაგნოსტიკა და მიმდინარე კონფიგურაციის შემოწმება** ძირითადად ***Privileged EXEC Mode ( router# )*** -ში ხდება. 
- თუ იმყოფებით კონფიგურაციის რეჟიმში (`router(config)#`) , ბრძანებების წინ დაწერეთთ `do` პრეფიქსის :     `do show users`.

- `Router# show running-config`  - - -    ***მიმდინარე  კონფიგურაციის ნახვა***. 
- `Router# show run`  ან `sh run`  - - -   შემოკლებით ზედა ბრძანება.. 
- `Router# show ip interface brief`:  - - -  ინტერფეისების ***სტატუსი და IP მისამართები*** ( ერთ-ერთი ყველაზე ხშირი ბრძანება ).
- `Router# show running-config | include username` - - - გამოიტანს ***არსებულ  უზერებს*** , ზედმეტი ინფოს გარეშე. 
- `Router# show run | include username` - - -  ზედას შემოკლებული ვერსია.  ***(არსებულ  უზერებს)*** .  
- `Router# show users` - - -  ვინ არის ***სისტემაში ამ წამს  შესული***  (  Console-ით, Telnet-ით ან SSH-ით ). 
	- **Line:** კავშირის ტიპს ( მაგალითად, `vty 0`).  
	- **User:** მომხმარებლის სახელს.  
	- **Host:** საიდან არის შემოსული (IP მისამართი).  
	- **Idle:** რამდენი ხანია, რაც მომხმარებელს აქტივობა არ ჰქონია.
- **`Router# show interfaces`** - - -  დეტალური სტატუსი თითოეულ პორტზე ( სიჩქარე, შეცდომები, ტრაფიკი ).
- `Router# show ip route` - - -  როუტერის მარშრუტიზაციის ცხრილის ჩვენება.
- **`Router# show startup-config` (ან `sh start`)** : - - - შენახული კონფიგურაციის ჩვენება ( NVRAM-დან ).
- **`Router# show version`**: - - -  ინფორმაცია სისტემურ აპარატურაზე , პროგრამულ ვერსიასა და კონფიგურაციის რეგისტრზე.
- **`Router# show cdp neighbors`**: - - -  მეზობლად მიერთებული **Cisco**-ს მოწყობილობების ჩვენება.
- 
- `Router# show ip route` - - -  **მარშუტიზაციის სიის ნახვა  ( *ip route* )**. ( directly connect ; static route ; rip . . . და სხვა )
- `show int trunk`  - - -  ***trunk*** ინტერფეისებს განახებს
- `show vlan brief` - - - ***vlan*** -ებს განახებს რომლებიც გაქვს ( **trunk** პორტები აქ არ ჩანს )
- `show int etherchannel` - - - აგრეგაციის ინტერფეისების დათვალიერება
- `Switch# show port-security interface fa 0/24`  - - - ინტერფეისის ***port-security*** მდგომარეობa. **ჩართულია/გამორთულია** და სხვა. 
- `Switch# show mac-address-table static`  - - -  სვიჩზე არსებული **static mac**  მისამართების ნახვა
- `Switch# show mac-address-table dynamic`  - - -  დინამიურად გაწერილი mac-ების ჩამონათვალი.
- `show ip dhcp ?`  - - -  ***DHCP*** -ის შესახებ ინფორმაციები `?` 
- `show ip access-lists` - - - 

##### მნიშვნელოვანი ნიუანსი!!!: ბრძანება `do`
თუ იმყოფებით კონფიგურაციის რეჟიმში ( მაგალითად: `Router(config)#` ან `Router(config-if)#`) , სტანდარტულად `show` ბრძანებები იქ არ მუშაობს.
რომ არ გამოხვიდეთ კონფიგურაციის რეჟიმიდან და მაინც ნახოთ სტატუსი, ბრძანებას წინ უნდა დაუწეროთ **`do`**:
- მაგალითად: `do show ip int br`


#### შენახვა და მართვა `Router#`

კონფიგურაციების შემდეგ ***აუცილებლად გადავდივართ პრივილეგირებულ რეჟმში*** `#` და ***ვასეივებთ***. 
**წინააღმდეგ შემთხვევაში როუტერის გამორთვის შემდეგ ყველაფერი წაიშლება!!!**

- `Router# copy running-config startup-config`: მიმდინარე კონფიგურაციის შენახვა NVRAM-ში.
- `Router# write` (ან `wr`): შენახვის მოკლე ბრძანება.
- `Router# write erase`: შენახული კონფიგურაციის (startup configuration) წაშლა.
- `Router# reload`: როუტერის გადატვირთვა.

#### საბაზისო უსაფრთხოება და გამართვა

- `Router(config)# hostname <name>` - - -  როუტერის სახელის შეცვლა.
- `Router(config)# enable secret <password>`- - -  პრივილეგირებული რეჟიმისთვის ძლიერი, დაშიფრული პაროლის დაყენება.
- `Router(config)# line console 0` - - -  კონსოლის ხაზის კონფიგურაციაში შესვლა.
- `Router(config-line)# password <password>` - - - ხაზისთვის (line) პაროლის მინიჭება.
- `Router(config-line)# login`- - -  პაროლის შემოწმების გააქტიურება შესვლისას.
- `Router(config)# service password-encryption` - - - პაროლები რომლებიც დაყენებულია სხვადასხვა რამეზე, show run-ში რომ არ გამოჩდეს და დაშიფრულად ჩანდეს. 

#### პრობლემების დიაგნოსტიკა (Troubleshooting)

- `Router# ping <ip>` : კავშირის შემოწმება დანიშნულების წერტილთან.
- **`Router# traceroute <ip>`**: დანიშნულების ადგილამდე მიმავალი მარშრუტის (გზის) მიკვლევა.
- **`Router# clear cdp table`**: **CDP** მეზობლების ცხრილის გასუფთავება.
- **`Router# show ip cef exact-route`**: კონკრეტული **IP** მარშრუტიზაციის გზების დეტალური შემოწმება (დებაგი).
- `Router(config)# no ip domain-lookup ` : ***DNS ძიების გათიშვა*** (არასწორი ბრძანების აკრეფისას დროის დაზოგვისთვის). 
	- (`Ctrl` + `Shift` + `6`) - - - თუ არ გათიშავ და გაგიჭედავს, ამით გააჩერებ პროცესს
