# git stash

`git stash` არის გიტის „დროებითი ჯიბე“, რომელშიც შეგიძლია სწრაფად ჩაყარო შენი მიმდინარე, დაუფიქსირებელი (commit-გაუკეთებელი) ცვლილებები, რათა სამუშაო გარემო სუფთა გახადო.

იგი ძალზე სასარგებლოა იმ სიტუაციაში, როცა კომპიუტერთან კოდი შუა გზაზე გაქვს, საქმის სასწრაფოდ შეწყვეტა გიწევს ან გჭირდება `git pull`-ის გაკეთება, მაგრამ ჯერ არ გინდა ნედლი და დაუსრულებელი ცვლილებების დაკომიტება.

* **`git stash`**: ინახავს შენს ყველა მიმდინარე ცვლილებას (როგორც `add`-იან ფაილებს, ისე უბრალოდ შეცვლილებს) და აბრუნებს პროექტს ბოლო კომიტის სუფთა მდგომარეობაში.
* **`git stash list`**: აჩვენებს შენახული სთეშების სიას (თუ დროთა განმავლობაში რამდენჯერმე გამოიყენე).
* **`git stash pop`**: აბრუნებს უკან შენახულ ცვლილებებს შენს სამუშაო სივრცეში და ავტომატურად შლის მათ სთეშების სიიდან.
* **`git stash apply`**: აბრუნებს ცვლილებებს, მაგრამ ტოვებს ასლს სთეშების სიაში (თუ გჭირდება, რომ იგივე ცვლილებები სხვაგანაც გამოიყენო).

**ტიპიური სცენარი შენი მუშაობისთვის:**
მუშაობ კომპიუტერზე, გაქვს დაუმთავრებელი ფაილები, უცებ გჭირდება `git pull --rebase`-ის გაშვება, მაგრამ გიტი შეცდომას გიგდებს, რადგან ადგილობრივი ფაილები შეცვლილი გაქვს. აკეთებ უბრალოდ `git stash`-ს, მერე უპრობლემოდ უშვებ `git pull --rebase`-ს და ბოლოს აკეთებ `git stash pop`-ს, რომ შენი დაუმთავრებელი კოდი ისევ ადგილზე დაბრუნდეს.
