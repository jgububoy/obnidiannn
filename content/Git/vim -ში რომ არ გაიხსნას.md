# vim-ში რომ არ გაიხსნას

იმისათვის, რომ მომავალში მერჯის დროს Vim-ის ფანჯარა ავტომატურად აღარ გაიხსნას და Git-მა სტანდარტული (ან სხვა) ტექსტური რედაქტორი გამოიყენოს, ან საერთოდ თავიდან აიცილოთ მსგავსი შუალედური ეკრანები, შეგიძლიათ გამოიყენოთ შემდეგი გზები:

## რებეისის (Rebase) მუდმივად გამოყენება:

თუ გსურთ, რომ `git pull` ავტომატურად აკეთებდეს რებეისს და მერჯ-ქომითის დაწერა არ მოგიწიოთ, დააყენეთ ეს პარამეტრი გლობალურად:

```bash
git config --global pull.rebase true

```


ამ ბრძანების შემდეგ, როცა `git pull`-ს გაუშვებთ, Git აღარ გახსნის Vim-ს ფანჯრის შესავსებად და ცვლილებებს ავტომატურად მიამაგრებს თავზე.

### უკან დაბრუნება :

ისევ რომ ჩართოთ და ძველ რეჟიმს დაუბრუნდეთ, ტერმინალში ჩაწერეთ:

```bash
git config --global --unset pull.rebase

```

თუ გსურთ, რომ კონკრეტულად გათიშოთ (ანუ მიუთითოთ, რომ `rebase` არ იყოს გამოყენებული და ძველი ნაგულისხმევად შერწყმის (`merge`) მეთოდი დაბრუნდეს), გამოიყენეთ ეს ბრძანება:

```bash
git config --global pull.rebase false

```


## სხვა რედაქტორის მითითება (მაგალითად VS Code, nano):

თუ მაინც გჭირდებათ მერჯის ქომითები, მაგრამ Vim-ის ნაცვლად გირჩევნიათ გრაფიკული რედაქტორი (როგორიცაა **VSCode**), დააყენეთ ის ნაგულისხმებ რედაქტორად:

```bash
git config --global core.editor "code --wait"
```

**nano**-ში რომ გამიხსნას: 
```shell
git config --global core.editor "nano"
```
