# Excel-ის ცხელი კლავიშები (Hotkeys) და ეფექტური ილეთები

Excel-ში ცხელი კლავიშების გამოყენება სამუშაო პროცესს რამდენჯერმე აჩქარებს. ქვემოთ წარმოდგენილია ძირითადი კლავიშთა კომბინაციები და ფუნქციური ილეთები, დაჯგუფებული კატეგორიების მიხედვით.

[Самые нужные комбинации клавиш Excel - YouTube](https://www.youtube.com/watch?v=eZmO9oJrkYM) 


## 1. უჯრებში გადაადგილება

- **`Ctrl` + ისრები (`↑`, `↓`, `←`, `→`)** — უწყვეტი მონაცემების დიაპაზონის ბოლო (კიდურ) უჯრაზე გადასვლა.
    
    - თუ ცხრილში ცარიელი უჯრებია, კურსორი გაჩერდება წყვეტამდე.
        
    - განმეორებით დაჭერა გადაგიყვანთ მომდევნო მონაცემთა ბლოკზე.
        
- **`Ctrl` + `Home`** — სამუშაო ფურცლის დასაწყისში (`A1` უჯრაზე) სწრაფი დაბრუნება.

## 2. უჯრებისა და დიაპაზონების მონიშვნა

- **`Shift` + ისრები** — მომდევნო უჯრების ეტაპობრივი მონიშვნა.
    
- **`Ctrl` + `Shift` + ისრები** — მთლიანი უწყვეტი დიაპაზონის მონიშვნა არჩეული მიმართულებით.
    
- **`Ctrl` + `A`** — უწყვეტი ცხრილის/მონაცემთა ბლოკის სრული მონიშვნა.
    
    - **ხელახალი დაჭერა (`Ctrl` + `A`):** მთელი სამუშაო ფურცლის (ყველა უჯრის) მონიშვნა.
        
    - **ობიექტების წაშლა/ფორმატირება:** თუ მონიშნულია დიაგრამა ან ობიექტი, `Ctrl` + `A`-ზე დაჭერით მოინიშნება ფურცელზე არსებული ყველა ობიექტი.  
        
- **`Shift` + `Space` (ჰარი)** — იმ სტრიქონის სრულად მონიშვნა, რომელშიც იმყოფება კურსორი.  
    
- **`Ctrl` + `Space` (ჰარი)** — იმ სვეტის სრულად მონიშვნა, რომელშიც იმყოფება კურსორი.


## 3. სტრიქონებისა და სვეტების დამატება, წაშლა, დამალვა

- **`Ctrl` + `+` (Numpad-ზე)** — ახალი სტრიქონის (არჩეულის ზემოთ) ან სვეტის (არჩეულის მარცხნივ) ჩასმა.
    - _ლეპტოპზე ციფრული ბლოკის (Numpad) გარეშე:_ **`Ctrl` + `Shift` + `=`**.
        
- **`Ctrl` + `-`** — მონიშნული სტრიქონის ან სვეტის წაშლა.
    
- **`Ctrl` + `9`** — მონიშნული სტრიქონის დამალვა.
    
- **`Ctrl` + `0`** — მონიშნული სვეტის დამალვა.
    
- **`Shift` + თაგვით გადათრევა** — სტრიქონის უსაფრთხოდ გადაადგილება (მონაცემთა გადაფარვისა და წაშლის გარეშე ჩასმა).

## 4. მონაცემთა კოპირება

- **`Ctrl` + `D` (Fill Down)** — ზედა უჯრის შიგთავსის, ფორმულის და ფორმატირების გადმოკოპირება ქვედა უჯრაში (ან მონიშნულ დიაპაზონში).
    
- **`Ctrl` + `R` (Fill Right)** — მარცხენა უჯრის შიგთავსის, ფორმულის და ფორმატირების გადმოკოპირება მარჯვენა უჯრაში.
    
## 5. ცხრილები, ფილტრები და სორტირება

- **`Ctrl` + `T`** — მონაცემთა უწყვეტი დიაპაზონის სწრაფი გარდაქმნა „ჭკვიან ცხრილად“ (Excel Table).
    
- **`Ctrl` + `Shift` + `L`** — ავტოფილტრების ჩართვა/გამორთვა მონაცემთა დიაპაზონის პირველი (სათაურების) სტრიქონისთვის.

## 6. ფორმატირება და მოქმედების გაამეორება

- **`Ctrl` + `1`** — უჯრების ფორმატირების ფანჯრის გახსნა (`Format Cells`).
    
- **`F4`** — ბოლო შესრულებული მოქმედების გამეორება (მაგალითად: უჯრის ფერის შეცვლა, გაერთიანება და ა.შ.).

## 7. ავტოჯამი (AutoSum)

- **`Alt` + `=`** — ავტოჯამის ფორმულის (`SUM`) ავტომატური ჩასმა.
    
    - სვეტის ქვეშ ან სტრიქონის მარჯვნივ ჩასმისას ავტომატურად იანგარიშებს მიმდებარე ციფრულ დიაპაზონს.
        
    - თუ მონიშნავთ მთლიან ცხრილს + ცარიელ ქვედა სტრიქონს და მარჯვენა სვეტს, `Alt` + `=` ერთდროულად დაითვლის ყველა ჯამს.

## 8. სწრაფი შევსება (Flash Fill)

- **`Ctrl` + `E`** — მონაცემების შაბლონის მიხედვით ავტომატური შევსება/დაშლა (მაგალითად, სრული სახელი და გვარის ცალკეულ სვეტებად დაყოფა).

## 9. ინტერფეისის მართვა

- **`Ctrl` + `Page Up` / `Ctrl` + `Page Down`** — სამუშაო ფურცლებს (Sheets) შორის სწრაფი გადართვა.
    
- **`Ctrl` + დაწკაპუნება ფურცლების ისრებზე** — პირველ ან ბოლო ფურცელზე გადასვლა.
    
- **`Ctrl` + `F6`** — ღია Excel-ის დოკუმენტებს (Workbooks) შორის გადართვა.
    
- **`Ctrl` + `F1`** — ინსტრუმენტების პანელის (Ribbon) დამალვა ან გამოჩენა.  
    
- **`Ctrl` + თაგვის გორგოლა** — მასშტაბის (Zoom) გაზრდა / შემცირება.
    
- **მასშტაბირება მონიშნულის მიხედვით:** მონიშნეთ სასურველი დიაპაზონი $\rightarrow$ დააწკაპუნეთ ქვედა მარჯვენა კუთხეში პროცენტულ მაჩვენებელზე $\rightarrow$ აირჩიეთ **„По выделению“** (Fit selection).
