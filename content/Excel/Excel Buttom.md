# Excel Buttom

> მინახავს ვიღაცას ქონდა ექსელის პროგრამაშ გაკეთებილი: ექსელის ფაილში რაღაც ღილაკი იყო გამოტანილი, დააჭერდი და მაგალითად კომპიუტერის ინფორმაციას გამოიტანდა (მაც, სახელი, ip ... ) როგორ და რა პრინციპით. კეთდება ეს ყველაფერი

ეს არის ძალიან პრაქტიკული და საინტერესო ფუნქცია, რომელსაც **VBA (Visual Basic for Applications)** ეწოდება. ეს არის პროგრამირების ენა, რომელიც ჩაშენებულია Microsoft Office-ის პროგრამებში და საშუალებას გაძლევთ მოახდინოთ პროცესების ავტომატიზაცია.

პრინციპი მარტივია: თქვენ წერთ პატარა კოდს (სკრიპტს), რომელიც „ესაუბრება“ ოპერაციულ სისტემას (Windows-ს), იღებს იქიდან ინფორმაციას და გადმოაქვს ექსელის უჯრებში.

აი, როგორ შეგიძლიათ ამის გაკეთება ნაბიჯ-ნაბიჯ:

### 1. ჩართეთ Developer Tab

ნაგულისხმევად, პროგრამირების პანელი დამალულია. მის გამოსაჩენად:

- დააჭირეთ მარჯვენა ღილაკით ექსელის ნებისმიერ ტაბს (მაგ. Home-ს).
    
- აირჩიეთ **Customize the Ribbon**.
    
- მარჯვენა ჩამონათვალში მონიშნეთ **Developer** და დააჭირეთ OK.
    

### 2. კოდის დაწერა (VBA)

ახლა საჭიროა იმ „ტვინის“ შექმნა, რომელიც ინფორმაციას მოიპოვებს:

1. გახსნილ **Developer** ტაბზე დააჭირეთ **Visual Basic**-ს.
    
2. გამოსულ ფანჯარაში აირჩიეთ მენიუ **Insert** > **Module**.
    
3. ჩააკოპირეთ შემდეგი კოდი:
    



```VBA
Sub GetPCInfo()
    Dim ws As Worksheet
    Set ws = ThisWorkbook.Sheets(1) 'ინფორმაციას ჩაწერს პირველ გვერდზე
    
    ws.Range("A1").Value = "კომპიუტერის სახელი:"
    ws.Range("B1").Value = Environ("COMPUTERNAME")
    
    ws.Range("A2").Value = "მომხმარებელი:"
    ws.Range("B2").Value = Environ("USERNAME")
    
    ' IP მისამართის მისაღებად ვიყენებთ Shell ბრძანებას
    Dim objWMI As Object, objNetAdapter As Object, colNetAdapters As Object
    Set objWMI = GetObject("winmgmts:\\.\root\cimv2")
    Set colNetAdapters = objWMI.ExecQuery("Select * from Win32_NetworkAdapterConfiguration where IPEnabled = True")
    
    Dim row As Integer: row = 3
    For Each objNetAdapter In colNetAdapters
        ws.Range("A" & row).Value = "IP მისამართი:"
        ws.Range("B" & row).Value = objNetAdapter.IPAddress(0)
        row = row + 1
    Next
End Sub
```


### 3. ღილაკის შექმნა

რომ არ დაგჭირდეთ კოდებში ძრომიალი, გამოვიტანოთ ლამაზი ღილაკი:

1. **Developer** ტაბზე დააჭირეთ **Insert**.
    
2. აირჩიეთ პირველივე სიმბოლო (**Button**).
    
3. დახატეთ ღილაკი ექსელის ფურცელზე.
    
4. ეგრევე ამოგიგდებთ ფანჯარას, სადაც უნდა აირჩიოთ ჩვენი შექმნილი მაკროსი: **GetPCInfo**.

### როგორ მუშაობს ეს სისტემა? (ლოგიკა)

- **Environ ფუნქცია:** ეს არის პირდაპირი კავშირი Windows-ის გარემოს ცვლადებთან. ის „კითხულობს“ იმ მონაცემებს, რომლებსაც სისტემა ისედაც ინახავს (სახელი, პროცესორი და ა.შ.).
    
- **WMI (Windows Management Instrumentation):** ეს უფრო რთული სისტემაა (გამოვიყენეთ IP-სთვის), რომელიც საშუალებას აძლევს პროგრამებს გამოითხოვონ დეტალური ინფორმაცია აპარატურაზე (Hardware).
    
- **ავტომატიზაცია:** ღილაკზე დაჭერით თქვენ ააქტიურებთ ამ „მოთხოვნას“, სისტემა პასუხობს და ექსელი ამ პასუხს წამებში ბეჭდავს უჯრებში.


> **მნიშვნელოვანი შენიშვნა:** ასეთი ფაილის შენახვისას აუცილებლად აირჩიეთ ფორმატი **Excel Macro-Enabled Workbook (.xlsm)**, თორემ კოდი წაიშლება.
