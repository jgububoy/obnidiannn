# პრობლემა - ფლეშკა ითხოვს ფორმატირებას(Format) 

### აღდგენის ინსტრუქცია (ეტაპობრივად)

[Как восстановить файлы и флешку одной командой Реквием - YouTube](https://www.youtube.com/watch?v=wbD9x2odG5Q) 

თუ ფლეშკა ფიზიკურად არ არის დამწვარი და მას სისტემა " ხედავს " ( თუნდაც შეცდომით ), გამოიყენეთ შემდეგი მეთოდი:

1. **შეაერთეთ ფლეშკა** კომპიუტერში. სისტემის მიერ შემოთავაზებულ ფორმატირებაზე დააჭირეთ **Cancel**-ს.
2. **გაარკვიეთ დისკის ასო:** გახსენით "This PC" ( File Explorer ) და ნახეთ, რა ასო აქვს მინიჭებული ფლეშკას ( მაგალითად: **E:**, **F:** ან **G:** ).
3. **გახსენით Command Prompt (CMD):** საძიებო ველში ჩაწერეთ `cmd` და გახსენით იგი.
4. **ჩაწერეთ ბრძანება:**

```powershell
chkdsk E: /f /r /x    ( სადაც `E:`-ს ნაცვლად წერთ თქვენი ფლეშკის შესაბამის ასოს ).
```

**ბრძანების განმარტება:**

- **chkdsk** — დისკის შემოწმება.
- **/f** — შეცდომების ავტომატური გასწორება.
- **/r** — დაზიანებული სექტორების პოვნა და ინფორმაციის აღდგენა.
- **/x** — დისკის იძულებითი გამოთიშვა პროცესის დასაწყებად.


5. **დაელოდეთ დასრულებას:** როდესაც პროცესი 100%-მდე ავა, ფლეშკა და მასზე არსებული ფაილები კვლავ ხელმისაწვდომი გახდება.

### **დასკვნა**

- **მიზეზი:** ხშირად პრობლემას ფაილური სისტემის შეცდომა ან ე.წ. "Bad sectors" იწვევს და არა ფიზიკური დაზიანება.
    
- **გაფრთხილება:** თუ ეს მეთოდი არ მუშაობს და კომპიუტერი ფლეშკას საერთოდ ვერ აღიქვამს (როგორც მოწყობილობას), შესაძლოა იგი ფიზიკურად იყოს დამწვარი და მისი შეკეთება შეუძლებელი იყოს.
