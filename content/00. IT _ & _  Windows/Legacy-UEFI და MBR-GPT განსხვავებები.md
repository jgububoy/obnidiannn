# Legacy-UEFI და MBR-GPT განსხვავებები


მარტივად რომ ვთქვათ, ეს არის "ხიდები" აპარატურასა (Hardware) და პროგრამულ უზრუნველყოფას (OS) შორის.
## 1. BIOS (Legacy) vs. UEFI

ეს არის პროგრამული ინტერფეისები, რომლებიც კომპიუტერის ჩართვისთანავე აქტიურდება.

- **Legacy (BIOS):** ძველი სტანდარტია (1970-იანებიდან). ის ამოწმებს აპარატურას და ეძებს "ჩამტვირთველს" დისკის პირველ სექტორში. მისი ინტერფეისი ძირითადად ტექსტურია (ლურჯი ეკრანი).
- **UEFI:** თანამედროვე სტანდარტია. ის უფრო სწრაფია, აქვს გრაფიკული ინტერფეისი (მაუსის მხარდაჭერით) და გააჩნია **Secure Boot** ფუნქცია, რომელიც იცავს სისტემას ვირუსებისგან ჩატვირთვის პროცესში.


|**მახასიათებელი**|**Legacy (BIOS)**|**UEFI**|
|---|---|---|
|**ჩატვირთვის სიჩქარე**|ნელი|სწრაფი (Fast Boot)|
|**ინტერფეისი**|მხოლოდ კლავიატურა, ტექსტური|მაუსი, გრაფიკა, ქსელი|
|**უსაფრთხოება**|დაბალი|მაღალი (Secure Boot)|
|**დისკის მაქს. მოცულობა**|2 TB-მდე|9.4 ZB-მდე (პრაქტიკულად ლიმიტის გარეშე)|

## 2. MBR vs. GPT

ესენი არის დისკის დაყოფის (Partition) სქემები. ისინი განსაზღვრავენ, როგორ ინახება ინფორმაცია სექციების (C, D დისკები) შესახებ.

- **MBR (Master Boot Record):** ძველი მეთოდი.
    
    - მაქსიმალური მოცულობა: **2 ტერაბაიტი**. თუ გაქვთ 4TB დისკი MBR-ზე, ნახევარს ვერ დაინახავთ.
    - მაქსიმუმ **4 ძირითადი (Primary)** სექცია.
        
- **GPT (GUID Partition Table):** თანამედროვე სტანდარტი.
    
    - ლიმიტი პრაქტიკულად არ აქვს.
    - შეგიძლიათ შექმნათ თითქმის შეუზღუდავი რაოდენობის სექცია (Windows-ზე 128).
    - ინახავს მონაცემების რამდენიმე ასლს დისკზე, რაც დაზიანების შემთხვევაში აღდგენას აადვილებს.


---

## 3. როგორ არიან ისინი ერთმანეთთან დაკავშირებული?

ეს ყველაზე მნიშვნელოვანი მომენტია:

1. **Legacy BIOS** მუშაობს მხოლოდ **MBR**-თან.
2. **UEFI** მუშაობს **GPT**-თან.

> **შენიშვნა:** თუ აინსტალირებთ Windows 10-ს ან 11-ს, აუცილებლად გამოიყენეთ **UEFI + GPT** კომბინაცია. Windows 11-ის ინსტალაციისთვის UEFI და Secure Boot სავალდებულო მოთხოვნაა.

---

### როგორ გავიგოთ, რა გვაქვს ახლა?

1. დააჭირეთ `Win + X` და აირჩიეთ **Disk Management**.
2. დააჭირეთ მარჯვენა ღილაკით თქვენს მთავარ დისკს (Disk 0).
3. აირჩიეთ **Properties** -> **Volumes**. იქ ნახავთ "Partition style"-ს.
