# windows -ში icon ის მოხსნა


Windows და macOS სხვადასხვა ენაზე „საუბრობენ“, როცა საქმე ფოლდერების ვიზუალურ მორგებას ეხება.

აი, რატომ ხდება ეს და როგორ მოვაგვაროთ:

### რატომ იკეტება ფოლდერი "Read-Only" რეჟიმში?

როდესაც Windows-ში ფოლდერს ხატულას (icon) უცვლით, სისტემა იმ ფოლდერის შიგნით ქმნის დამალულ სისტემურ ფაილს, სახელად 

`desktop.ini`.

1. **ატრიბუტების კონფლიქტი:** Windows ამ ფოლდერს ავტომატურად ანიჭებს "Read-Only" ან "System" სტატუსს, რათა დაიცვას თქვენი არჩეული icon-ის პარამეტრები.
2. **macOS-ის რეაქცია:** როდესაც ამ ფოლდერს Apple-ის კომპიუტერში ხსნით, macOS ხედავს ამ Windows-ის მიერ დადებულ „ბოქლომს“ (Read-Only ატრიბუტს) და უსაფრთხოების მიზნით გიზღუდავთ მასში ფაილების ჩაწერას ან წაშლას.
    

---

### როგორ გამოვასწოროთ?

თუ გსურთ, რომ ფოლდერი ორივე სისტემაში ჩვეულებრივად მუშაობდეს, რამდენიმე გზა არსებობს:

#### 1. ყველაზე მარტივი გზა (Windows-იდან)

დააბრუნეთ ფოლდერის ხატულა სტანდარტულზე.

- მარჯვენა ღილაკით დააჭირეთ ფოლდერს -> **Properties** -> **Customize**.
    
- აირჩიეთ **Change Icon** და შემდეგ დააჭირეთ **Restore Defaults**.
    
- ეს წაშლის `desktop.ini` ფაილს და მოხსნის Read-Only შეზღუდვას.
    

#### 2. ატრიბუტის ხელით მოხსნა (Command Prompt)

თუ გინდათ, რომ icon-იც დარჩეს და macOS-მაც „გაატაროს“, შეგიძლიათ სცადოთ ატრიბუტის მოხსნა Windows-ის ტერმინალიდან:

1. გახსენით **PowerShell**.
    
2. ჩაწერეთ შემდეგი ბრძანება ( შეცვალეთ `folder_path` თქვენი ფოლდერის მისამართით ): 

```bash
attrib -r -s "C:\your_folder_path"
```



ეს ბრძანება მოხსნის **Read-only (-r)** და **System (-s)** სტატუსს.


#### 3. ფაილური სისტემის შემოწმება

თუ ფოლდერი გარე მეხსიერებაზეა (USB ან HDD), დარწმუნდით, რომ ფაილური სისტემა არის **ExFAT**.

- თუ მეხსიერება არის **NTFS** ფორმატში, Mac მასზე ფაილებს საერთოდ ვერ ჩაწერს (მხოლოდ წაიკითხავს), მიუხედავად იმისა, შეცვლით თუ არა icon-ს.
    

---

### პატარა რჩევა

თუ ხშირად გიწევთ ფაილების მიმოცვლა Windows-სა და Mac-ს შორის, უმჯობესია მოერიდოთ ფოლდერების დიზაინის შეცვლას (Custom Icons), რადგან `desktop.ini` ( Windows ) და `.DS_Store` (  [Mac](../Git/_%20DS_Store%20(%20git%20).md)  ) ფაილები მუდმივად ქმნიან მსგავს პატარა კონფლიქტებს.
