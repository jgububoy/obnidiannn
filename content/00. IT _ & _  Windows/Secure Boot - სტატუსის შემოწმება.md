# Secure Boot - სტატუსის შემოწმება

***Secure Boot**-ის სტატუსის შემოწმება* ძალიან მარტივია პირდაპირ Windows-იდან.
ამისათვის ორი ძირითადი გზა არსებობს:

#### მეთოდი 1: System Information (ყველაზე მარტივი)

1. დააჭირეთ კლავიატურაზე `Win + R` ღილაკებს.
2. ჩაწერეთ `msinfo32` და დააჭირეთ **Enter**.
3. გამოსულ ფანჯარაში, მარცხენა მენიუში აირჩიეთ **System Summary** (ჩვეულებრივ თავიდანვე არჩეულია).
4. მარჯვენა მხარეს მოძებნეთ ორი მნიშვნელოვანი პუნქტი:
    - **BIOS Mode:** აქ უნდა ეწეროს **UEFI** (თუ Legacy წერია, ესე იგი კონვერტაცია ბოლომდე არ დასრულებულა).
    - **Secure Boot State:** აქ უნდა ეწეროს **On**.

---

#### მეთოდი 2: PowerShell (სწრაფი გზა)

თუ ბრძანებების გამოყენება გირჩევნიათ:

1. დააჭირეთ მარჯვენა ღილაკით Start მენიუს და აირჩიეთ **Windows PowerShell (Admin)** ან **Terminal (Admin)**.
2. ჩაწერეთ შემდეგი ბრძანება და დააჭირეთ Enter: `Confirm-SecureBootUEFI`  
3. თუ პასუხად მიიღებთ **True**, ეს ნიშნავს, რომ Secure Boot აქტიურია. თუ მიიღებთ **False** ან შეცდომას, ეს ნიშნავს, რომ ის გამორთულია ან თქვენი სისტემა Legacy რეჟიმშია.

---

#### რა უნდა ქნათ, თუ წერია "Off" ან "Unsupported"?

თუ BIOS Mode არის **UEFI**, მაგრამ Secure Boot მაინც **Off**-ია, ეს ნიშნავს, რომ პარამეტრი BIOS-შია შესაცვლელი:

- შედით BIOS-ში (ჩვეულებრივ `F2` ან `Del` ჩართვისას).
- მოძებნეთ **Security** ან **Boot** ტაბი.
- იპოვეთ **Secure Boot** და გადაიყვანეთ **Enabled** მდგომარეობაში.
- ***გაითვალისწინეთ:*** ზოგჯერ საჭიროა "Restore Factory Keys"-ის დაჭერა იქვე, რათა Secure Boot გააქტიურდეს.
