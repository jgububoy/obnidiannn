# Windows Software RAID

Windows სისტემაში ეს აბსოლუტურად შესაძლებელია ყოველგვარი დამატებითი აპარატურის (RAID Controller-ის) გარეშე. ამას **Software RAID** ეწოდება და ოპერაციული სისტემა თავად უზრუნველყოფს დისკების მართვას.

ამის გაკეთების ორი ძირითადი გზა არსებობს:

### 1. Storage Spaces (თანამედროვე მეთოდი)

ეს არის Windows 10-სა და 11-ში არსებული სტანდარტული და ყველაზე მოქნილი ხელსაწყო. ის საშუალებას გაძლევთ გააერთიანოთ სხვადასხვა ზომის დისკები ერთ "აუზში" (Pool).

- **Simple (RAID 0):** აერთიანებს მოცულობებს და ზრდის სისწრაფეს, მაგრამ ერთი დისკის დაზიანების შემთხვევაში მონაცემები სრულად იკარგება.
    
- **Mirror (RAID 1):** ერთი დისკის ასლს აკეთებს მეორეზე. თუ ერთი გაფუჭდება, მონაცემები გადარჩება.
    

---

### 2. Disk Management (კლასიკური მეთოდი)

ეს მეთოდი წლებია არსებობს და იყენებს "Dynamic Disks" კონცეფციას. მისი გააქტიურება ხდება `diskmgmt.msc` ბრძანებით.

- **Spanned Volume:** უბრალოდ აბამს ერთ დისკს მეორეს (არ ზრდის სისწრაფეს).
    
- **Striped Volume (RAID 0):** მონაცემებს ანაწილებს ორ დისკზე ერთდროულად სისწრაფისთვის.
    
- **Mirrored Volume (RAID 1):** ქმნის სარკულ ასლს (ხელმისაწვდომია მხოლოდ Windows Pro/Enterprise ვერსიებზე).
    

---

### მნიშვნელოვანი რჩევები:

> **გაფრთხილება:** პროცესის დაწყებისას დისკები უნდა იყოს ცარიელი ან დაფორმატებული, რადგან მათი "დინამიურ" რეჟიმში გადაყვანა ჩვეულებრივ შლის არსებულ მონაცემებს.

- **სისტემური დისკი:** პროგრამული RAID-ით Windows-ის ჩამტვირთავი (C:) დისკის გაერთიანება საკმაოდ რთულია და ხშირად არასტაბილურია. უმჯობესია ეს მეთოდი გამოიყენოთ მხოლოდ დამატებითი (Storage) დისკებისთვის.
    
- **სისწრაფე:** ვინაიდან პროცესებს პროცესორი (CPU) მართავს და არა სპეციალური ჩიპი, ძალიან ძველ კომპიუტერებზე შესაძლოა მცირე დატვირთვა იგრძნობოდეს (თუმცა თანამედროვე პროცესორებისთვის ეს შეუმჩნეველია).
