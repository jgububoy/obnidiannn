# Wine


**Wine** (აბრევიატურა: **W**ine **I**s **N**ot an **E**mulator) არის პროგრამული ფენა, რომელიც საშუალებას გაძლევთ გაუშვათ **Windows-ის პროგრამები** სხვა ოპერაციულ სისტემებზე, როგორიცაა **Linux, macOS და BSD**.

მიუხედავად იმისა, რომ სახელი ამბობს "ეს არ არის ემულატორი", ბევრი მას ასე აღიქვამს. სინამდვილეში, ის უფრო "თარჯიმანია".
.
***Wine*** არის  **[Proton](Proton.md)** - ის წინამორბედი, წინაპარი. 
თუ ***Wine*** არის "**საფუძველი**", ***Proton*** არის მისი გაუმჯობესებული, "**გაქოქილი**" ვერსია, რომელიც სპეციალურად გეიმინგისთვისაა ოპტიმიზებული.

### როგორ მუშაობს Wine?

როდესაც Windows-ის პროგრამა ცდილობს შეასრულოს რაიმე მოქმედება (მაგალითად, ფანჯრის გახსნა ან ფაილის ჩაწერა), ის აგზავნის ბრძანებას Windows-ის API-ზე. Wine იჭერს ამ ბრძანებას და მომენტალურად "თარგმნის" მას ისეთ ბრძანებად, რომელიც Linux-ს ან macOS-ს ესმის.

### რატომ არის ის სასარგებლო?

1. **სისწრაფე:** რადგან ის არ ახდენს მთლიანი Windows სისტემის ემულირებას (განსხვავებით VirtualBox-ისგან), პროგრამები თითქმის ისეთივე სისწრაფით მუშაობენ, როგორც მშობლიურ გარემოში.
    
2. **ინტეგრაცია:** Windows-ის პროგრამა ჩანს და იქცევა ისე, თითქოს ის თქვენი სისტემის ნაწილია — შეგიძლიათ მისი ფანჯრის ზომის შეცვლა, "copy-paste" და სხვა.
    
3. **თამაშები:** Wine არის საფუძველი ისეთი ტექნოლოგიების, როგორიცაა **Proton** (რომელსაც Steam იყენებს), რაც საშუალებას იძლევა Windows-ის თამაშები იდეალურად გაეშვას Linux-ზე.
    

### ძირითადი ტერმინები:

- **Wine Prefix:** ეს არის იმიტირებული "C: დისკი". ყოველ პროგრამას შეიძლება ჰქონდეს თავისი იზოლირებული გარემო, რათა ერთმანეთს ხელი არ შეუშალონ.
    
- **Winetricks:** დამხმარე სკრიპტი, რომელიც გეხმარებათ აუცილებელი კომპონენტების (მაგალითად, .NET Framework ან DirectX) მარტივად დაინსტალირებაში.
    

---

### სად გამოიყენება?

- თუ გაქვთ Linux სერვერი ან სამუშაო სადგური და გჭირდებათ კონკრეტული Windows პროგრამა (მაგალითად, Photoshop-ის ძველი ვერსია ან სააღრიცხვო პროგრამა).
    
- თამაშებისთვის, რომლებიც არ არსებობს Linux-ისთვის.
    

თუ IT სფეროში მუშაობთ და Linux-თან გაქვთ შეხება, Wine-ის ცოდნა ძალიან დაგეხმარებათ "legacy" (ძველი) სისტემების ინტეგრაციაში. გაინტერესებთ მისი კონფიგურაციის დეტალები თუ კონკრეტული პროგრამის გაშვება გსურთ?
