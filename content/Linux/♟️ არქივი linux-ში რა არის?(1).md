# არქივი linux-ში რა არის?

**არქივი** არის ერთი ან რამდენიმე ფაილისგან შედგენილი ერთიანი ფაილი, რომელიც დაკომპლექტებულია ორი ძირითადი მიზნისთვის:

* **სივრცის დაზოგვა:** მონაცემების შეკუმშვა (Compression), რომ ნაკლებ ადგილს იკავებდეს დისკზე.
* **მოხერხებულობა:** მრავალი ფაილისა და საქაღალდის ერთ კომპაქტურ ფაილად გაერთიანება (მაგალითად, ელფოსტით გასაგზავნად).

არქივირების ფორმატებს შორის მნიშვნელოვანი ტექნიკური განსხვავებებია, ამიტომ არჩევანი დამოკიდებულია კონკრეტულ ამოცანაზე.

## მთავარი ფორმატების შედარება
[♟️ არქივი linux-ში ( მანიპულაცია )(2)](♟️%20არქივი%20linux-ში%20(%20მანიპულაცია%20)(2).md) 

* **ZIP:** **უნივერსალური სტანდარტი.** მხარდაჭერილია ნებისმიერ ოპერაციულ სისტემაში (Windows, macOS, Linux) ყოველგვარი დამატებითი პროგრამის გარეშე. არის სწრაფი, მაგრამ შეკუმშვის კოეფიციენტით საშუალო დონის. იდეალურია ყოველდღიური ფაილების გასაზიარებლად.
* **RAR:** **მაღალი შეკუმშვა და დაცვა.** უზრუნველყოფს ფაილების საუკეთესო შეკუმშვას და აქვს დაზიანებული არქივების აღდგენის უნიკალური ფუნქცია (Recovery Record). უარყოფითი მხარეა ის, რომ ფორმატი პროპრიეტარულია (დახურული კოდის) და უფასოდ ძირითადად მხოლოდ გახსნაა შესაძლებელი.
* **TAR (Tarball):** **Linux/Unix სისტემების სტანდარტი.** სუფთა სახით `tar` მხოლოდ აერთიანებს ფაილებს ერთ კრებულად და **არ არკუმშავს** (ამიტომ თითქმის ყოველთვის გამოიყენება შეკუმშვასთან ერთად, მაგალითად `.tar.gz` ან `.tgz`). მისი მთავარი უპირატესობაა ფაილების უფლებების (Permissions), მფლობელების და სიმბოლური ლინკების (Symlinks) სრულად შენარჩუნება, რაც კრიტიკულია ლინუქსისთვის.

## იხსნება თუ არა TAR Windows სისტემაში?

**კი, იხსნება.**

* **მშობლიური მხარდაჭერა:** თანამედროვე **Windows 10 და Windows 11** სისტემებს აქვთ ჩაშენებული მხარდაჭერა. Windows 11-ის File Explorer-ს თავისუფლად შეუძლია `tar` და `tar.gz` არქივების გახსნა (ამოარქივება).
* **ბრძანების სტრიქონი:** PowerShell-ში ან CMD-ში შეგიძლიათ გამოიყენოთ სტანდარტული ბრძანება:
`tar -xf archive.tar`
* **მესამე მხარის პროგრამები:** ისეთი პოპულარული არქივატორები, როგორიცაა **7-Zip** ან **WinRAR**, სრულად უჭერენ მხარს TAR არქივების როგორც გახსნას, ისე შექმნას.
