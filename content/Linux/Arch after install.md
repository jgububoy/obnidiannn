# 7 основных вещей, которые нужно сделать после установки Arch Linux

#### 0. Обновите вашу систему

Возможно, вы уже использовали последний выпуск, но рекомендуется проверить наличие последнего обновления для вашей системы Arch:

```bash
sudo pacman -Syu
```
<br>

#### 1. Установка X-сервера, среды рабочего стола и диспетчера дисплея

Перед установкой среды рабочего стола **(DE)** вам необходимо установить [X-сервер,](http://www.linfo.org/x_server.html) который является самым популярным [сервером отображения](https://itsfoss.com/display-server/) . 

```bash
sudo pacman -S xorg
```

По завершении используйте любую из следующих команд, чтобы установить свою любимую среду рабочего стола .

Чтобы установить **GNOME:**

```bash
sudo pacman -S gnome gnome-extra
```

Чтобы установить **Cinnamon:**

```bash
sudo pacman -S cinnamon nemo-fileroller
```

Чтобы установить **XFCE**:

```bash
sudo pacman -S xfce4 xfce4-goodies
```

Чтобы установить **KDE**:

```bash
sudo pacman -S plasma
```

Чтобы установить **MATE**:

```bash
sudo pacman -S mate mate-extra
```

Вам также понадобится [диспетчер отображения](https://itsfoss.com/display-manager/) для входа в среду рабочего стола. Для удобства вы можете установить [LXDM](https://wiki.archlinux.org/index.php/LXDM) .

```bash
pacman -S lxdm
```

После установки вы можете включить запуск каждый раз при перезагрузке системы.

```bash
systemctl enable lxdm.service
```

Перезагрузите систему, и вы увидите экран входа в систему LXDM, выберите среду рабочего стола из списка и войдите в систему.
<br>
#### 2. Установите ядро LTS.

Перед установкой ядра LTS [проверьте используемую версию ядра Linux](https://itsfoss.com/find-which-kernel-version-is-running-in-ubuntu/) .

```bash
uname -r
```

Чтобы установить **ядро** ​​**LTS** и заголовки Linux **LTS**, введите следующую команду:

```bash
sudo pacman -S linux-lts
```
<br>

```bash
sudo pacman install linux-lts-headers
```

После этого вы можете удалить старые ядра, введя команду ниже. Однако я предпочитаю оставить его на случай, если что-то пойдет не так, я могу загрузить другую версию ядра Linux.

```bash
sudo pacman -Rs linux
```

<br>

#### 3. Установка Yaourt

[Yaourt](https://archlinux.fr/yaourt-en) означает еще один инструмент репозитория пользователей, который можно использовать для поиска, загрузки и установки пакетов из официального репозитория, а также из AUR.

[Пользовательский репозиторий Arch](https://itsfoss.com/aur-arch-linux/) или [AUR](https://wiki.archlinux.org/index.php/Arch_User_Repository) - это управляемый сообществом репозиторий для пользователей Arch, содержащий описания пакетов для компиляции пакета из исходного кода и его установки. 

AUR содержит множество полезных приложений, которых нет в основном репозитории, которые можно установить из AUR с помощью Yaourt. Yaourt похож на [Synaptic Package Manager](https://itsfoss.com/synaptic-package-manager/) , и его можно установить, выполнив следующие действия:

Откройте файл **/etc/pacman.conf** и добавьте следующие строки внизу:

```bash
[archlinuxfr]
```

```bash
SigLevel = Never
```

```bash
Server = http://repo.archlinux.fr/$arch
```

Сохраните изменение. Установите **Yaourt** с помощью следующей команды

```bash
sudo pacman -Syu yaourt
```

Используйте команду ниже, чтобы синхронизировать **Yaourt** с **AUR**:

```bash
yaourt –Syy
```

<br>

#### 4. Установите GUI Package Manager Pamac.

Менеджером пакетов по умолчанию для Arch Linux является [Pacman](https://wiki.archlinux.org/index.php/pacman) (менеджер пакетов),

Однако иногда сложно говорить командами**. Pamac** предоставляет возможность графического интерфейса для Pacman и работает как **Synaptic Package Manager** или **GNOME Software.**

Pamac служит инструментом графического интерфейса для установки или обновления пакетов и хорошо работает с Arch User Repository **AUR.**

**Как установить Pamac:**

Прежде чем вы сможете использовать **Pamac**, вам необходимо сначала установить **Yaourt** (или **Packer**). После этого введите следующую команду в терминале, чтобы установить **Pamac****.**

```bash
yaourt -S pamac-aur
```

<br>

#### 6. Установка продуктивного ПО

Для повседневного использования и настройки вашей системы Arch для продуктивного использования вам потребуются некоторые базовые приложения, такие как офисный пакет, почтовый клиент, веб-браузер и т. Д.

```bash
sudo pacman -S libreoffice thunderbird firefox gedit flashplugin aria2 dropbox gparted 
```

**Aria2** - менеджер загрузок, **LibreOffice** - самый популярный офисный пакет с открытым исходным кодом, **Thunderbird** - кроссплатформенный клиент почты и чата, **Firefox** - бесплатный веб-браузер с открытым исходным кодом, **Gedit** - редактор, **flashplugin** устанавливает flash, **Dropbox** - для хранения ваших файлов в любое время.

Наряду с этим вам потребуются менеджеры архивов.

```bash
sudo pacman -S p7zip p7zip-plugins unrar tar rsync
```

#### 7. Настройка внешнего вида рабочего стола Arch Linux

Вы можете настроить свой **Arch Linux**, установив несколько хороших плоских **тем** или инструмент мониторинга **conky**.

Некоторые из наиболее популярных тем - **Arc** **GTK**, **flatplat**, **Vertex** и **Numix**

```bash
yaourt -S arc-gtk-theme flatplat-theme-git vertex-themes
```

```bash
sudo pacman -S numix-themes
```

**Установка Conky**

**Conky** - это бесплатное приложение для управления системой, которое может отслеживать и отображать использование памяти, статистику ЦП, дисковое хранилище, подкачку, температуру ЦП и многое другое.

```bash
sudo pacman -S conky
```

Вы можете [настроить conky самостоятельно, для](https://itsfoss.com/conky-gui-ubuntu-1304/) чего потребуется немного покопаться в файле 

 **~ / .****conkyrc** или вы можете загрузить свой любимый из Интернета и заменить файл **conkyrc** по умолчанию. Подробное руководство по **conky** и его настройке можно найти на [веб-сайте Arch Linux.](https://wiki.archlinux.org/index.php/Conky)

**Дополнительный совет:**

В любой момент, если вы захотите удалить какое-либо приложение (и его зависимости), вы можете использовать следующие команды:

```bash
sudo pacman -R package-name
```

Он удаляет пакет без удаления зависимостей. Если вы хотите удалить зависимости, но исключив те, которые используются другим приложением, поможет следующая команда:

```bash
sudo pacman -Rs package-name
```
