# Arch Linux - pacman - как обновить репозитории и пакеты ОС. 

## Arch Linux - pacman - как обновить репозитории и пакеты ОС

Для того чтобы обновить _репозитории_ и пакеты ОС нужно воспользоваться командой:

```bash
pacman -Syu
S  ---  stands for sync   ( обозначает синхронизацию )
y  ---  is for refresh local   (  обновление локальных файлов  ) 
u  ---  is for system update   ( обновления системы )
```

Важный момент - заглавная буква должна быть первой. 
...
**pkg.tar.xz**  —  стандартный **tar + xz**, возможно с дополнительными управляющими файлами. Используется *Arch Linux.*

### **Основные опции менеджера пакетов pacman:**

```bash
-S    – установка программ в archlinux;
-Sw   - скачать пакет но не устанавливать;
-U    - установить локальный пакет;
-s    – поиск пакета;
-i    – информация;
-u    – обновить пакеты;
-y    – обновить списки пакетов из репозиториев;
-dd   – игнорирование зависимостей;
-g    – запрос информации о группе;
-l    – вывод пакетов в виде списка;
-o    – вывод в файл;
-R    – удаление;
-Q    – запрос к базе данных установленных пакетов;
-F    – поиск по файлам;
-D    – задание и изменение цели установки уже имеющегося пакета;
-R    - удалить пакет;
-Rn   - удалять резервные копии конфигурационных файлов;
-Rs   - удалять зависимости пакета;
```

```bash
pacman -Syu                обновить списки пакетов из репозиториев и обновить пакеты
pacman -Syyu               Для одновременой синхронизации с репозиториями и обновления своей системы  
pacman -S [pkg]            Установка отдельных пакетов (включая зависимости)

pacman -Rs [pkg]           Удалить пакет и те его зависимости, которые не нужны никаким другим пакетам 
pacman -Rns                Pacman также сохраняет конфигурационные файлы, возникающие в процессе работы установленных программ
pacman -Sc                 Очистка кэша от уже установленных пакетов

pacman -Ql                 расширенная список всех установленных  пакет

pacman -Qm                 перечисляет установленные -вручную- пакеты
pacman -Qs [pkg]
pacman -Qi [pkg] 
pacman -Qii [pkg]          Перечислить информацию о пакете
```

**Сироты**   -  то есть установлены пакеты, которые больше ***не используется*** как чи-то зависимости и не предназначены для какой либо цели:

```bash
pacman -Qdt                             ---  Список ненужных пакетов
sudo pacman -Rns [pkg] $(pacman -Qdtq)  ---  Удалите ненужные пакеты
```

**установить** пакеты уже **загруженные** в систему (название файла должно заканчиваться на **pkg.tar.xz**): 

```bash
sudo pacman -U [/путь к пакету/][название пакета.pkg.tar.xz] 
sudo pacman -U ~/Загрузки/[leafpad.pkg.tar.xz]
```

```bash

```

## AUR (Arch User Repository)



### Что такое Arch User Repository (AUR)

**AUR** — это  управляемый сообществом репозиторий для пользователей *Arch.*   **AUR** был  создан с целью облегчения и организации процесса обмена пакетами  сообществом. Он содержит описания пакетов  (**PKGBUILD**),  которые позволяют  вам скомпилировать  пакет из исходного кода с помощью **makepkg**, а затем  установить его через **pacman**.

**PKGBUILD**  —  *скрипт*, используется Arch Linux, содержащий информацию о том, как получить, скомпилировать и собрать бинарный пакет. Все такие скрипты находятся в Arch User Repository (*AUR*).

Пакеты в Arch Linux создаются с помощью утилиты [makepkg,](https://wiki.archlinux.org/title/Makepkg) а информация хранится в файле [PKGBUILD](https://wiki.archlinux.org/title/PKGBUILD) .   При  **makepkg**  апуске он ищет **PKGBUILD**  в текущем каталоге и следует инструкциям в нем, чтобы получить  необходимые файлы и / или скомпилировать их для упаковки в файл пакета **(`pkgname.pkg.tar.zst`).**    Полученный пакет содержит двоичные файлы и инструкции по установке, готовые к установке с помощью [pacman](https://wiki.archlinux.org/title/Pacman) .

**example**:      `makepkg -si`  

**options**:        [link](https://man.archlinux.org/man/makepkg.8)

- **-s, --syncdeps**    ---   Установите недостающие зависимости с помощью *pacman*. Если зависимости  времени сборки или выполнения не найдены,         									 pacman попытается разрешить  их. В случае успеха недостающие пакеты будут загружены и установлены.
- **-i, --install**           ---  Установите или обновите пакет после успешной сборки с помощью pacman
- 



Пакет Arch - это не более чем **tar**-архив или **tarball**, сжатый с помощью [zstd (1)](https://man.archlinux.org/man/zstd.1) , который содержит следующие файлы, сгенерированные **makepkg**:

- Бинарные файлы для установки.
- `.PKGINFO`: содержит все метаданные, необходимые pacman для работы с пакетами, зависимостями и т. д.
- `.BUILDINFO`: содержит информацию, необходимую для воспроизводимых сборок. Этот файл присутствует только в том случае, если пакет собран с помощью pacman 5.1 или новее. См. [BUILDINFO (5)](https://man.archlinux.org/man/BUILDINFO.5) .
- `.MTREE`: содержит хэши и временные метки файлов, которые включены в локальную  базу данных, чтобы pacman мог проверить целостность пакета.
- `.INSTALL`: необязательный файл, используемый для выполнения команд после этапа установки / обновления / удаления. (Этот файл присутствует только в том случае, если он указан в `PKGBUILD`.)
- `.Changelog`: необязательный файл, хранящийся у сопровождающего пакета, документирующий изменения пакета. (Он присутствует не во всех пакетах.)


### Что такое Yay?

**[Yay](https://pingvinus.ru/note/yay)** — вспомогательный инструмент Arch Linux AUR, написанный на Go.    Он поможет вам автоматически устанавливать пакеты из PKGBUILD.

#### Установка

При миграции с другого помощника **AUR** можно просто установить **Yay** с этим помощником Альтернативно, первоначальная установка **Yay** может быть выполнена клонированием **PKGBUILD** и построением с помощью ***makepkg*** :

Перед началом работы убедитесь, что установлена группа пакетов **base-devel**.

- pacman -S --needed git base-devel

- git clone https://aur.archlinux.org/yay.git

- cd yay

- makepkg -si

### . . . далее . . .

- sudo pacman -S git

- git clone https://aur.archlinux.org/yay.git

- cd yay

- makepkg -si

Так же возможно установить через *pamac* или командой  "*sudo pacman -S yay"*



#### Поддержка

Вся поддержка, связанная с **Yay**, должна  запрашиваться через GitHub. Поскольку Yay официально не поддерживается  Arch Linux, не следует искать поддержку на форумах, комментариях AUR или других официальных каналах.

#### Примеры пользовательских операций:

- `yay -S [pkg]`        ---    установки пакета из AUR
- `yay -G [pkg]`        ---    Загрузить PKGBUILD из ABS или AUR.
- `yay -Ss [pkg]`      ---   найти пакет в AUR и официальных репозиториях
- `yay -Syu `           ---    обновить все пакеты из AUR и официальных репозиториев
- `yay -Pu`              ---    вывести список пакетов, которые необходимо обновить
- `yay -Yc`              ---    удалить нежелательные зависимости
- `yay -Ps`              ---    Печать статистики системы
- `yay -Y --gendb`    ---    Создание базы данных пакетов разработки, используемой для обновления разработки
