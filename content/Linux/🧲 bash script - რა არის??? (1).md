# Что такое bash

**Bash** —   არის ბრძანებების პროცესორი, რომელიც მუშაობს როგორც ინტერაქტიულ რეჟიმში (ტერმინალის ფანჯარაში), ისე ფაილებიდან (სკრიპტებიდან) ბრძანებების წაკითხვით.
**Bash** - - -  также может читать команды из файла, который называется **скриптом** (или сценарием).

## რა არის  script

- **განმარტება:** ***სკრიპტი*** (სცენარული ენა) არის მაღალი დონის ბრძანებების თანმიმდევრობა, რომელსაც რიგრიგობით კითხულობს და ასრულებს პროგრამა-**ინტერპრეტატორი** — ჩვენს შემთხვევაში ეს არის ბრძანებების სტრიქონი, ანუ **bash**.

- **ფაილის სტრუქტურა:** სკრიპტი წარმოადგენს ჩვეულებრივ ტექსტურ ფაილს, სადაც ჩამოთვლილია ის ბრძანებები, რასაც ტერმინალში ხელით ვწერთ ხოლმე, და მითითებულია ის პროგრამა, რომელმაც ეს ბრძანებები უნდა შეასრულოს.

- **მუშაობის პრინციპი:** სისტემის ჩამტვირთველს არ შეუძლია გარემოს ცვლადებთან მუშაობა, ამიტომ მას სჭირდება იმ პროგრამის ზუსტი გზის მიწოდება, რომლის გაშვებაც გვსურს. ამის შემდეგ ის სკრიპტს გადასცემს ამ პროგრამას და იწყება შესრულების პროცესი.
