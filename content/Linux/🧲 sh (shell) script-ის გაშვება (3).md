# sh (shell) script-ის გაშვება

1. **სკრიპტის** ფაილი უნდა გადავაკეთოთ ***შესრულებად/executed***" ფაილად :

   ```bash
   chmod +x (ფაილის სრული სახელი)
   ```

2. ახლა გავუშვებთ მოცემულ ფაილს 2 მეთოდით:
   **ა.**    
   ```bash
   ./(ფაილის სრული სახელი)
   ```

   **ბ.**   
   ```bash
    sudo sh (ფაილის სრული სახელი)
    bash script.sh
   ```
