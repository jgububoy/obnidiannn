# არქივი linux-ში

## უბრალოდ დაარქივება
```shell
sudo tar cvf book.tar text.txt
```

**sudo (Superuser Do):** - - - ანიჭებს მომხმარებელს ადმინისტრაციულ (**root**) უფლებებს. ეს საჭიროა იმ შემთხვევაში, თუ მიმდინარე საქაღალდეში ფაილების ჩაწერის ან წაკითხვის შეზღუდვები გაქვთ.

**tar (Tape Archive):** - - - ***ძირითადი პროგრამა, რომელიც გამოიყენება ფაილების ერთ არქივში გასაერთიანებლად ( კომპრესიის გარეშე )***.

- **c (Create):** - - - (`--create`) — ეუბნება ბრძანებას, რომ ახალი არქივი უნდა შეიქმნას.
- **v (Verbose):** - - - (`--verbose`) — პროცესის მიმდინარეობისას ეკრანზე გამოაქვს დეტალური ინფორმაცია (იმ ფაილების სიას, რომლებიც არქივში ემატება).
- **f (File):** - - - (`--file`) — მიუთითებს, შემდეგი სიტყვა იქნება შესაქმნელი არქივის სახელი (`book.tar`).
- **book.tar და text.txt:** - - -  **`book.tar`** არის საბოლოო არქივის სახელი, რომელიც შეიქმნება, ხოლო **`text.txt`** არის საწყისი ფაილი, რომელსაც არქივში ამატებთ.


## კომპრესიით (შეკუმშვა)
მოცემული ბრძანება  წინა ვარიანტისგან განსხვავებით არა მხოლოდ აერთიანებს ფაილს არქივში, არამედ ***კუმშავს*** მას `gzip` ალგორითმის გამოყენებით:

```bash
sudo tar cvfz book.tar.gz text.txt
```

დეტალურად ახალი დროშა და მთლიანი სტრუქტურა ასე გამოიყურება:

- **z (Gzip compression):** - - - (`--gzip`) — ეუბნება `tar` ბრძანებას, რომ არქივის შექმნის პარალელურად ფაილი ***შეკუმშოს*** `gzip` მეთოდით, რათა მისმა ზომამ დისკზე ნაკლები ადგილი დაიკავოს.
- **cvfz ერთად:** - - -  დროშები `c`, `v`, `f` და `z` ერთმანეთზეა მიბმული: იქმნება არქივი (`c`), მიმდინარეობს პროცესის ჩვენება (`v`), იქმნება მითითებული სახელით (`f`) და ერთდროულად იკუმშება (`z`).
- **book.tar.gz და text.txt:** - - - **`book.tar.gz`** არის უკვე შეკუმშული არქივის სახელი 
(ხშირად ამ ფორმატს `tgz`-ადაც მოიხსენიებენ. 
	`gz` -შეიძლებოდა არ მიგვეწერა, ეს ერთგვარი აღმნიშვნელია იმისა რომ ეს ფაილი შეკუმშულია), ხოლო **`text.txt`** არის საწყისი ფაილი.


> [!NOTE] შემოწმება
> არქივის წარმატებით შექმნისა და მისი შეკუმშული ზომის შესამოწმებლად გაუშვით ბრძანება `ls -lh`

.
## დირექტორიის დაარქივება: 
დავაარქივე პაპკა რომელიც იყო `~/Documents` დირექტორიაში. და დაარქივებული ფაილი, სახელად **direqtoria** შეიქმნა სადაც ახლა ვიმყოფები იმ კატალოგში( desktop ).

```shell
boy@boy-Machine:~/Desktop$ sudo tar cvfz direqtoria.tar.gz ~/Documents/papka/
```

 **../Downloads/direqtoria.tar.gz** - - - ამ მისამართზე შეიქმნას არქივი :
 ```shell
 boy@boy-Machine:~/Desktop$ sudo tar cvfz ../Downloads/direqtoria.tar.gz ~/Documents/papka/
 ```

არქივის შიგთავსის **ნახვა**. ( ანუ რა ფაილებია შიგნით ):
```shell
tar -tf direqtoria.tar.gz
```
.
## ამოარქივება: 
#### 1. როდესაც ***არქივი შეკუმშლი არაა***. `.tar` 

`sudo tar xvf book.tar` - - - 

#### 2. როდესაც ***არქივი შეკუმშლია***  `.tar.gz`

`sudo tar xvfz book.tar.gz` - - - 
ანალოგიურად, როგორც შექმნისას, აქაც თითოეული ასო ასრულებს თავის როლს:

- **x (Extract):** - - - (`--extract`) — ეუბნება `tar` ბრძანებას, რომ არქივიდან ფაილების ამოღება (ამოარქივება) სურს.
- **v (Verbose):** - - - (`--verbose`) — პროცესის მიმდინარეობისას ეკრანზე გამოაქვს იმ ფაილების სია, რომლებიც არქივიდან იხსნება.
- **f (File):** - - - (`--file`) — მიუთითებს საარქივო ფაილის სახელს, რომელთანაც ოპერაცია უნდა შესრულდეს.
- **z (Gzip):** - - - (`--gzip`) — ავტომატურად ხსნის `gzip`-ით გაკეთებულ შეკუმშვას გახსნის პროცესშივე.

#### 3. მისამართების გაწერა:

მაგალითად როდესაც **desktop** -დან გვინდა ფაილის **Document** საქაღალდეში გადმოვაარქივოთ:

```shell
tar xvfz direqtoria.tar.gz --directory=../Documents/    - სწორია
tar xvfz direqtoria.tar.gz --directory=~/Documents/     - არასწორია
```

`../Documents/` ამის მაგივრად რომ ჩაგვეწერა `~/Documents/` შეცდომას ამოაგდებდა, რადგან: 

**`tar` ბრძანება (და ზოგადად ლინუქსის მრავალი ბრძანება) *tilde*-ს (`~`) არ ხსნის ავტომატურად**, როდესაც ის მიბმულია დროშის ტოლობის ნიშნულთან (`--directory=~/Documents`). `tar` ეძებს ზუსტად სახელად `~`-იან ფოლდერს და არა მომხმარებლის მთავარ (Home) დირექტორიას.

ამ პრობლემის მოსაგვარებლად გამოიყენეთ სრული მისამართი (`/home/boy/...`) ან უბრალოდ ტალღის ნიშანი ცალკე:

```bash
tar xvfz direqtoria.tar.gz -C ~/Documents/
```

- **-C დროშა:** - - - (`--directory`-ს მოკლე ფორმა) — ეუბნება `tar`-ს, რომ არქივი უნდა გახსნას მითითებულ მისამართზე.
- **მთავარი მისამართი:**
იმისათვის, რომ `~` სწორად გაიშალოს, უმჯობესია გამოიყენოთ `-C ~/Documents/` ფორმატი (სივრცით გამოყოფილი და არა ტოლობით მიბმული).
