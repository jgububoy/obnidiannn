# შესრულებადი(исполняемый , Executable) ფაილი

**პროგრამა - - -  არის ინსტრუქციების ერთობლიობა, რომლებსაც პროცესორი მონაცემებზე დაყრდნობით რიგრიგობით ასრულებს გარკვეული შედეგის მისაღებად.** 

***"გასაშვები" (შესრულებადი / исполняемый / Executable) ფაილი*** არის ფაილი, რომელიც შეიცავს ინსტრუქციების ან ბრძანებების ერთობლიობას, რომლებსაც პროცესორი (ან შესაბამისი პროგრამა-ინტერპრეტატორი) თანმიმდევრობით ასრულებს გარკვეული შედეგის მისაღებად.

* **განსხვავება ლინუქსსა და Windows-ს შორის:** Windows-ში ფაილის გასაშვებობას მისი გაფართოება (მაგ. `.exe`) განსაზღვრავს, ხოლო ლინუქსში ფაილი გასაშვებად მხოლოდ მაშინ იქცევა, როდესაც მას ფაილურ სისტემაში მინიჭებული აქვს სპეციალური ***შესრულებადობის ფლაგი*** (`+x`). თავად ფაილის შიგთავსი ამ უფლების მინიჭებისას არ იცვლება.
* **შიგთავსი:** ასეთი ფაილი შეიძლება იყოს როგორც პირდაპირ პროცესორისთვის განკუთვნილი ბინარული კოდი, ისე ტექსტური სკრიპტი, რომელსაც გასაშვებად შესაბამისი ინტერპრეტატორი (მაგალითად, `bash`) ამუშავებს.


იმისათვის, რომ სისტემამ ტექსტური ფაილი ან გადმოწერილი  ***სკრიპტი პროგრამად აღიქვას და გაუშვას*** , აუცილებელია მას  ***შესრულებადობის(execute) ფლაგის მინიჭება***.:   [script გაშვება](🧲%20sh%20(shell)%20script-ის%20გაშვება%20(3).md) 

```bash
chmod +x <file_name> 
```

- **შედეგი:** ფაილს ემატება შესრულების (`execute`) უფლება და ის მზად არის გასაშვებად.

>***p.s.*** - - - თუ კატეგორიას არ მივუთითებთ (როგორც `chmod +x` შემთხვევაში), ბრძანება ავტომატურად ვრცელდება **ყველა კატეგორიაზე** ერთდროულად: მფლობელზე (`u`), ჯგუფზე (`g`) და სხვებზე (`o`). შედეგად, ამ ფაილის გაშვება (execution) ყველას შეეძლება.
>გაითვალისწინეთ, რომ ფაილის რეალურად გასაშვებად, `x` (executable) უფლებასთან ერთად, აუცილებელია **`r` (read / წაკითხვის)** უფლებაც ჰქონდეს იმავე მომხმარებელს, წინააღმდეგ შემთხვევაში სისტემა სკრიპტს ან პროგრამას მაინც ვერ წაიკითხავს და არ გაუშვებს.
>ანუ :
>`chmod +x <file_name>`  და `chmod a+x <file_name>` ერთიდაიგივეა. 

## როგორ გავხადოთ ფაილი შესრულებადი Linux-ში?

Linux-ის ოპერაციულ სისტემაში ფაილების ფლაგების სამართავად გამოიყენება **უტილიტა** ***chmod***.
უტილიტას გამოძახების **სინტაქსია**:

$ `chmod` `კატეგორია` `მოქმედება` `ფლაგი` `ფაილის_მისამართი`

- **კატეგორია** - - -  ფლაგები შეიძლება დაწესდეს სამი კატეგორიისთვის: ***ფაილის მფლობელისთვის, ჯგუფისთვის და ყველა დანარჩენი მომხმარებლისთვის***(ყველა მომხმარებელი). ბრძანებაში ისინი მითითებულია შესაბამისად სიმბოლოებით: **u (user)**, **g (group)**, **o (other)**, **a (all)**.
- **მოქმედება** - - -  `+` (**პლუსი**), ნიშნავს ფლაგის დაყენებას;  `-` (**მინუსი**) — ფლაგის მოხსნას.
- **ფლაგi** - - -  ერთ-ერთი ხელმისაწვდომი ფლაგიდან: `r` (**წაკითხვა**), `w` (**ჩაწერა**), `x` (**შესრულება**).


მაგალითად, Linux-ში ფაილის მფლობელისთვის სკრიპტის გასაშვებად (აღსრულებად) გადასაყვანად საკმარისია შესრულდეს:

```bash
 chmod u+x адрес_файла
```

ეს "ზედა" ბრძანება უმეტეს შემთხვევაში საკმარისია. 
მაგრამ თუ გვინდა, რომ ფაილის გაშვება **სხვა მომხმარებლებმაც შეძლონ**, საჭიროა სხვა კატეგორიების
— `g`-სა და `o`-ს — მითითებაც:

```bash
 chmod ugo+x адрес_файла
```

გასაშვები (აღსრულების) **ფლაგის მოხსნა** ძალიან მარტივია. 
გამოიყენება ზუსტად იგივე ბრძანება, ოღონდ ***მინუსი*** ნიშნით:

```bash
 chmod u-x адрес_файла
```
