# Shell ( Bash vs ZSH )

## SHELL 
**Shell (გარსი)** არის კომპიუტერული პროგრამა, რომელიც წარმოადგენს შუამავალს მომხმარებელსა და ოპერაციული სისტემის „გულს“ ( კერნელს ანუ Kernel-ს ) შორის.

სახელიც აქედან მოდის — როგორც კაკალს აქვს ***გარსი (Shell)***, რომელიც მის ყველაზე მთავარ ნაწილს ფარავს და იცავს, ისე ეს პროგრამა ფარავს ოპერაციული სისტემის რთულ შიდა მექანიზმებს და მომხმარებელს კომფორტულ საშუალებას აძლევს მასთან ურთიერთობისთვის.

### როგორი არსებობს Shell?

გარსი ძირითადად ორი ტიპისაა:

1. **CLI (Command Line Interface - ტერმინალის გარსი):**
	* სადაც საქმე გვაქვს სუფთა ტექსტთან და ბრძანებების აკრეფასთან.
	* **მაგალითები:** სწორედ ესენია **Bash** და **ZSH**, ასევე Windows-ის ძველი **CMD** და თანამედროვე **PowerShell**

2. **GUI (Graphical User Interface - გრაფიკული გარსი):**
	* სადაც საქმე გვაქვს მაუსთან, ფანჯრებთან, ღილაკებთან და ხატულებებთან (Icons).
	* **მაგალითები:** Windows-ის სამუშაო მაგიდის გარსი (Explorer), macOS-ის Finder/Desktop, ან Linux-ის სამუშაო გარემო (GNOME, KDE).

როდესაც ტერმინალში ვსაუბრობთ სიტყვა **Shell**-ზე, უმეტეს შემთხვევაში ვგულისხმობთ სწორედ **ტექსტურ გარსს (CLI)** — ანუ პროგრამას, რომელიც უსმენს შენს აკრეფილ ბრძანებებს (`ls`, `cd`, `git` და ა.შ.), თარგმნის მათ კომპიუტერისთვის გასაგებ ენაზე და უკან გიბრუნებს პასუხს.


## Bash ან ZSH 

> მოკლედ: 
> 1. ტერმინალის ფანჯარა ( **terminal** ) - - -  არის ვიზუალი (გრაფიკა), 
> 2. **Bash** და **ZSH** - - - არიან ის შინაგანი დამუშავების სისტემები, რომლებიც ამ ფანჯრის უკან მუშაობენ.

**Bash და ZSH არ არის გრაფიკული მხარე ან ვიზუალი.** 
პირიქით, ისინი სწორედ რომ **„ტექსტური ტვინები“** (***პროგრამები***) არიან, რომლებიც შენს ბრძანებებს ამუშავებენ. 
თავად ტერმინალის შავ ფანჯარას კი რაიმე განსაკუთრებული გრაფიკული ინტელექტი არ გააჩნია — ის მხოლოდ ეკრანზე ტექსტს აჩვენებს.

რომ წარმოიდგინოთ ეს ყველაფერი სტრუქტურულად:

1. ***ტერმინალის ფანჯარა (Terminal Emulator / GUI)*** :  მაგალითად, macOS-ის Terminal, iTerm2 ან Linux-ის GNOME Terminal.  - - -  აი  ეს არის **ნამდვილი გრაფიკული მხარე (ვიზუალი)**. ეს არის უბრალოდ ფანჯარა, სადაც ფონს ცვლი, ფერებს არჩევ და შრიფტს ზომავ.
2. ***Shell ( Bash ან ZSH )*:** - - - ეს არის ფანჯრის შიგნით ***გაშვებული პროგრამა***. როდესაც კლავიატურიდან ტექსტს აკრიფებ, ტერმინალის ფანჯარა ამ ტექსტს უგზავნის **Bash**-ს ან **ZSH**-ს. ეს უკანასკნელი კითხულობს ბრძანებას, აანალიზებს და ოპერაციულ სისტემას ეუბნება, რა გააკეთოს.

## ZSH (Z shell)

**ZSH** (Z shell) არის ძლიერი და მრავალფუნქციური **Unix/Linux სავაჭრო გარსის (Command Line Shell)** ტიპი, რომელიც გამოიყენება ტერმინალში ბრძანებების შესასრულებლად და სკრიპტების დასაწერად. ის წარმოადგენს უფრო ძველ და პოპულარულ **Bash** გარსის თანამედროვე და გაუმჯობესებულ ალტერნატივას (მიუხედავად იმისა, რომ თავსებადია Bash-თან).

დღესდღეობით ZSH არის სტანდარტული ნაგულისხმევი (Default) Shell-ი macOS-ში (Catalina-დან მოყოლებული) და ხშირად გამოიყენება Linux-ის მომხმარებლების მიერ.

### ZSH-ის ძირითადი უპირატესობები:

* **უკეთესი ავტომატური შევსება (Auto-completion):** ბრძანებების, ფაილების და არგუმენტების აკრეფისას ტაბით (`Tab`) მუშაობს ბევრად ჭკვიანურად. გთავაზობს ჩამოსათვლელ მენიუს, სადაც ისრების გამოყენებით შეგიძლია არჩევა.
* **გაფართოებული ძებნა ისტორიაში:** თუ აკრიფებ ბრძანების დასაწყისს და დააჭერ ისრებს ზემოთ/ქვემოთ, ტერმინალი მოძებნის მხოლოდ იმ ბრძანებებს, რომლებიც ამ სიტყვით იწყებოდა.
* **თემები და პერსონალიზაცია:** პოპულარული ფრეიმვორკების (როგორიცაა **Oh My Zsh**) დახმარებით მარტივია ვიზუალური მხარის შეცვლა — ტერმინალში შეიძლება გამოჩნდეს Git-ის მიმდინარე ბრენჩი, საქაღალდის სტატუსი, ფერები და ა.შ.
* **მძლავრი გლობინგის (Globbing) სისტემა:** ფაილების ძებნისა და ფილტრაციისთვის იყენებს ბევრად მოქნილი სინტაქსს, ვიდრე Bash.
* **ცდომილებების ავტომატური კორექცია:** თუ ბრძანება შეცდომით აკრიფე, ZSH სცადადებს გამოიცნოს შენი განზრახვა და შეგასწოროს.

მოკლედ რომ ვთქვათ, ZSH არის ინსტრუმენტი, რომელიც ტერმინალთან მუშაობას უფრო სწრაფს, მოსახერხებელს და ვიზუალურად მიმზიდველს ხდის.
### რაც შეეხება ბრძანებებს:

* **მსგავსება:** რადგან ორივე Unix-სისტემების ტერმინალის გარსია, ძირითადი ბრძანებები (მაგალითად: `ls`, `cd`, `pwd`, `mkdir`) **ორივეგან ზუსტად ერთნაირია**.
* **განსხვავება:** ზოგიერთი შიდა სინტაქსი და განსაკუთრებით **ავტომატური შევსება, კონფიგურაცია და ეკრანზე გამოტანის წესები** ZSH-ს და Bash-ს განსხვავებული აქვთ. ამიტომ არის, რომ ზოგიერთი რთული სკრიპტი, რომელიც Bash-ისთვის არის დაწერილი, შეიძლება ZSH-ში პატარა ცვლილებას მოითხოვდეს (თუმცა ზოგადი ბრძანებები ძირითადად ემთხვევა).

## Oh My Zsh
[macbook terminal customisations](../00.%20Apple/macbook%20terminal%20customisations.md) 

**Oh My Zsh** არის ძალიან პოპულარული, ღია კოდის მქონე ფრეიმვორკი (კრებულების ერთობლიობა), რომელიც შექმნილია იმისათვის, რომ ***ZSH-ის კონფიგურაცია და მართვა გაგიმარტივოს***.

როდესაც შენ თავად აყენებ **ZSH**-ს, მისი პარამეტრების ხელით გამართვა, ლამაზი თემების დაყენება ან დამატებითი ფუნქციების (მაგალითად, ფერადი Git სტატუსების) ინტეგრაცია საკმაოდ ბევრ რთულ და რუტინულ კონფიგურაციას მოითხოვს. **Oh My Zsh** ამ ყველაფერს შენ ნაცვლად აკეთებს.

### მთავარი შესაძლებლობები, რასაც Oh My Zsh ამატებს:

* **მზა ვიზუალური თემები:** მოყვება ასობით წინასწარ გამზადებული თემა (მაგალითად, ცნობილი `agnoster`), რომლებიც ტერმინალს ძალიან ლამაზად და ინფორმაციულად აწყობენ. ტერმინალშივე ხედავ Git-ის ბრენჩს, ფაილების სტატუსს, შეცდომებს და ა.შ.
* **მზა მოდულები (Plugins):** აქვს 270-ზე მეტი ჩაშენებული პლაგინი ისეთი ინსტრუმენტებისთვის, როგორიცაა **Git, Docker, Python, z, sudo** და ა.შ. მაგალითად, Git-ის პლაგინი საშუალებას გაძლევს ბრძანებები შემოკლებით აკრიფო (`gst` ნაცვლად `git status`-ისა).
* **ავტომატური განახლება:** პერიოდულად თავადვე ახსენებს თავს და მარტივი ბრძანებით შეგიძლია მისი უახლეს ვერსიამდე განახლება.
* **მარტივი მართვა:** ერთი მარტივი ფაილის (`.zshrc`) მეშვეობით შეგიძლია თემებისა და პლაგინების ჩართვა-გათიშვა.

მოკლედ რომ ვთქვათ, თუ ZSH არის ძლიერი „ძრავა“, **Oh My Zsh** არის მზა, კომფორტული და ლამაზი „კომპლექტაცია“, რომლითაც ტერმინალთან მუშაობა მაქსიმალურად მარტივი და სასიამოვნო ხდება.
