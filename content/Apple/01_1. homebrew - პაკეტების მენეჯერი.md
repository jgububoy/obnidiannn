# 🍺 Homebrew : macOS პაკეტების მენეჯერი

[Homebrew — The Missing Package Manager for macOS (or Linux)](https://brew.sh) 

**Homebrew** არის დე-ფაქტო სტანდარტული პაკეტების მენეჯერი **macOS**-ისთვის. ის ავსებს იმ ცარიელ ადგილს, რომელიც Apple-მა დატოვა, და მომხმარებელს აძლევს საშუალებას მართოს პროგრამული უზრუნველყოფა პირდაპირ ტერმინალიდან.
## 🚀 რატომ უნდა გამოვიყენოთ Homebrew?

[Используем Homebrew - YouTube](https://www.youtube.com/watch?v=3JrLhReusrY) 

ის მართავს ორი ტიპის პროგრამას:

1. **[Formulae ( ფორმულები )](01_3.%20homebrew%20-%20Formulae%20(%20CLI%20ფორმულები%20).md)** **CLI** ხელსაწყოები და ბიბლიოთეკები (`git`, `python`, `node`).
2. **[Casks (კასკები)](01_4.%20homebrew%20-%20cask%20(%20GUI%20).md)**  გრაფიკული აპლიკაციები (`google-chrome`, `visual-studio-code`, `spotify`).

***მთავარი განსხვავებები***:

|---|---|---|

|**რა იტვირთება?**|საწყისი კოდი (Sources)|გამზადებული პაკეტი (.app / .dmg)|
|**ინსტალაცია**|კომპილაცია/აწყობა ლოკალურად|ფაილის გადატანა Applications-ში|
|**მაგალითი**|Python, Git, Node.js|Google Chrome, Slack, Photoshop|


## 🛠 ინსტალაცია და პირველი ნაბიჯები

**Homebrew**-ს დასაყენებლად გახსენით ტერმინალი და გამოიყენეთ ოფიციალური ბრძანება [brew.sh](https://brew.sh/)-დან:

```shell
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

#### ძირითადი ბრძანებების ცხრილი:

| **ბრძანება**                              | **აღწერა**                                                                                               |
| ----------------------------------------- | -------------------------------------------------------------------------------------------------------- |

| `brew upgrade`                            | ყველა ***დაინსტალირებული პაკეტის*** განახლება. ***მხოლოდ Formulae - ები***                               |
| `brew upgrade -cask (პროგრამის სახელი)`   | განაახლებს ***casks***-ებს, ოღონდ ყველას სახელი უნდა ჩამოწერო                                            |
| `brew upgrade --cask $(brew list --cask)` | ყველა ***casks***-ს განაახლებს                                                                           |

| `brew list`                               | დაინსტალირებული პროგრამების და კასკების სიის ნახვა                                                       |
| `brew list --cask`                        |                                                                                                          |
| `brew search <სახელი>`                    | სასურველი პროგრამის ძებნა ბაზაში                                                                         |
| `brew info <სახელი>`                      | პროგრა,ის(ფორმულას) ინფორმაცია                                                                           |
| `<პროგრამის სახელი>`                      | პროგრამის გაშვება                                                                                        |
| `brew cleanup`                            | **უსარგებლო (ძველი) ფაილებისგან გასუფთავება:** ინსტალაციის შემდეგ დარჩენილი დროებითი ფაილების წასაშლელად |
|                                           |                                                                                                          |

## 🐧 Linux-თან შედარება

Homebrew ასრულებს იმავე როლს, რასაც პოპულარული მენეჯერები Linux დისტრიბუტივებში.

|**ფუნქცია**|**Homebrew (macOS)**|**APT (Ubuntu)**|**Pacman (Arch)**|
|---|---|---|---|
|**ინსტალაცია**|`brew install`|`sudo apt install`|`sudo pacman -S`|
|**წაშლა**|`brew uninstall`|`sudo apt remove`|`sudo pacman -R`|
|**განახლება**|`brew upgrade`|`sudo apt upgrade`|`sudo pacman -Syu`|

#### 💡 რა ხდის Homebrew-ს განსაკუთრებულს?

- **Root წვდომა:** ინსტალაციისთვის ხშირად არ სჭირდება `sudo`.
- **Cask სისტემა:** შეუძლია სრულფასოვანი GUI აპლიკაციების მართვა.
- **Git ბაზა:** მთელი სისტემა ეყრდნობა Git-ს, რაც მას მოქნილს ხდის.

.

## 📦 Brew vs ხელით ინსტალაცია:
### რატომ არის Brew უკეთესი?

1. **ცენტრალიზებული განახლება:** `brew upgrade` ერთდროულად განაახლებს ყველა პროგრამას.
2. **სისუფთავე:** აპლიკაციები თავსდება კონკრეტულ დირექტორიებში, რაც სისტემას არ ნაგვიანებს.
3. **ავტომატიზაცია:** შესაძლებელია ე.წ. **Brewfile**-ის შექმნა, რომლითაც ახალ კომპიუტერზე ყველა პროგრამას ერთ წუთში აღადგენთ.


**რჩევა:** სანამ რაიმე პროგრამის საძებნელად ბრაუზერში შეხვალთ, სცადეთ `brew search <სახელი>`. შემთხვევათა 99%-ში ის უკვე ხელმისაწვდომია Brew-ს ბაზაში.
### 1. საიტიდან გადმოწერა და ინსტალაცია (ტრადიციული გზა)

როცა პროგრამას ოფიციალური საიტიდან იწერთ (`.dmg` ან `.pkg` ფაილით):

* **ინსტალაციის პროცესი:** ხსნით ფაილს და აპლიკაციას გადაათრევთ `Applications` საქაღალდეში (ან გადიხართ ოსტატის/Installer-ის ეტაპებს).
* **განახლებები:** თითოეულმა პროგრამამ თავად უნდა შეამოწმოს განახლებები, ან თქვენ უნდა შეხვიდეთ საიტზე და თავიდან გადმოწეროთ ახალი ვერსია.
* **მომხმარებლის გამოცდილება:** კარგია მსხვილი, გრაფიკული პროგრამებისთვის (მაგ: Photoshop, Chrome, Office), სადაც ვიზუალური ინსტალაცია გირჩევნიათ.

### 2. Homebrew-თი ინსტალაცია (ტერმინალის გზა)

Homebrew არის macOS-ის პაკეტების მენეჯერი (Command Line ინსტრუმენტი). ბრძანებით (მაგ: `brew install --cask google-chrome`) პროგრამა ავტომატურად იწერება და ყენდება.

* **ავტომატური განახლება:** ერთი ბრძანებით (`brew upgrade`) შეგიძლიათ სისტემაში არსებული ყველა პროგრამის ერთდროულად განახლება.
* **მოხერხებულობა დეველოპერებისთვის:** იდეალურია სწრაფი ინსტალაციისთვის, ძირითადად მცირე ზომის უტილიტებისა და საპროგრამო工具ებისთვის (Node.js, Git, Python და ა.შ.), ასევე პოპულარული აპლიკაციებისთვის (`--cask` პარამეტრით).
* **სივრცის დაზოგვა:** ტერმინალიდან მუშაობა ზოგავს დროს და თავიდან გაცილებთ რეკლამებსა და არასწორ საიტებზე მოხვედრის რისკს.

#### მაგალითი: Google Chrome-ის ინსტალაცია: 

რეკომენდებული გზა (Brew):**

```bash
brew install --cask google-chrome
```

_პროცესი ავტომატურია: გადმოწერა, დაყენება და ნაგვის გასუფთავება ხდება თავისით._
ამ დროს `brew` თავად:

1. უკავშირდება Google-ის სერვერს.
2. გადმოწერს უახლეს `.dmg` ფაილს.
3. თავისით "ამოაარქივებს" (mount).
4. გადაიტანს Chrome-ს `Applications` საქაღალდეში.
5. წაშლის ნარჩენ საინსტალაციო ფაილებს.

### მთავარი განსხვავებების ცხრილი

| მახასიათებელი | საიტიდან გადმოწერა | Homebrew |
| --- | --- | --- |
| **ინსტალაციის მეთოდი** | გრაფიკული (Drag-and-Drop) | ტერმინალიდან ბრძანებით |
| **განახლება** | პროგრამა ინდივიდუალურად აკონტროლებს | ყველაფერი ერთდროულად (`brew upgrade`) |
| **სირთულე** | ძალიან მარტივი ყველასთვის | მოითხოვს ტერმინალთან მუშაობის მცირე გამოცდილებას |


## homebrew -ს გადმოწერილი *საინსტალაციოები*: 

**Homebrew** გადმოწერილ ფაილებს ( ე.წ. "**Bottles**" ან არქივებს ) სპეციალურ ქეშ-საქაღალდეში ინახავს, **სანამ მათ დააინსტალირებდეს**.

- MacBook-ში Homebrew გადმოწერილ ფაილებს ინახავს **Caches** დირექტორიაში:
`~/Library/Caches/Homebrew`

- ტერმინალიდან პირდაპირ ამ საქაღალდეში გადასვლა, ჩაწერეთ:
`open ~/Library/Caches/Homebrew` 

- მისამართის მონახვა, თუ სად ინახავს  კონკრეტული **Homebrew ვერსია** ფაილებს:
`brew --cache`  
ეს ბრძანება დაგიბრუნებთ საქაღალდის ზუსტ გზას (Path). როგორც წესი, გადმოწერილი ფაილები არის `.tar.gz` ან `.bottle.tar.gz` ფორმატში.

### მნიშვნელოვანი ინფორმაცია ქეშის შესახებ

Homebrew **ავტომატურად არ შლის** ძველ გადმოწერილ ფაილებს ინსტალაციის შემდეგ, რაც დროთა განმავლობაში დიდ ადგილს იკავებს დისკზე.

| **ბრძანება**               | **რას აკეთებს**                                                                                                                   |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `brew --cache`             | მისამართის მონახვა                                                                                                                |
| `brew cleanup -n`          | გაჩვენებთ, რამდენი ადგილის გამოთავისუფლებაა შესაძლებელი (წაშლის გარეშე).                                                          |
| `brew cleanup`             | წაშლის ყველა ***ძველ ვერსიას*** და დროებით ფაილს ქეშიდან.                                                                         |
| `rm -rf $(brew --cache)`   | ***მთლიანად ასუფთავებს*** გადმოწერილ ფაილებს ( `~/Library/Caches/` -ში , მთლიანად შლის საქაღალდე `homebrew` -ს ).                 |
| `brew cleanup --prune=all` | `~/Library/Caches/Homebrew` საქაღალდეში წაშლის ***Download*** და ***caches*** საქაღალდეებში ჩაყრილ ფაილებს( **საინსტალაციოებს** ) |
|                            |                                                                                                                                   |

ეს ფაილები ინახება იმისთვის, რომ თუ მომავალში იგივე პროგრამის ხელახალი ინსტალაცია დაგჭირდებათ, Homebrew-მ ის აღარ გადმოწეროს ინტერნეტიდან და დაზოგოს დრო.


მას შემდეგ, რაც პროგრამა დაინსტალირდება, Homebrew მას გადაიტანს თავის სამუშაო გარემოში (ჩვეულებრივ `/opt/homebrew/Cellar` ან `/opt/homebrew/Caskroom`), ხოლო ორიგინალ გადმოწერილ არქივს (`.tar.gz` ან `.dmg`) ტოვებს ქეშში.

აი, რა უნდა იცოდეთ მათი წაშლის შესახებ:

### 1. "საინსტალაციოს" ხელით წაშლა უსაფრთხოა?

**დიახ, სრულიად უსაფრთხოა.** თუ ამ საქაღალდეებს დაცლით:

- დაინსტალირებული პროგრამები ჩვეულებრივ გააგრძელებენ მუშაობას.
- ერთადერთი "მინუსი" ისაა, რომ თუ მომავალში ამავე პროგრამის წაშლა და ხელახალი ინსტალაცია მოგინდებათ, Homebrew-ს მოუწევს ფაილის ინტერნეტიდან თავიდან გადმოწერა.

### 2. სწორი გზა გასასუფთავებლად

მიუხედავად იმისა, რომ შეგიძლიათ ხელით გადაყაროთ ეს ფაილები ნაგვის ყუთში (**Trash**), უმჯობესია გამოიყენოთ **Homebrew**-ს ჩაშენებული მექანიზმი, რომელიც მხოლოდ ზედმეტ ფაილებს წაშლის:

მხოლოდ ძველი ვერსიების წაშლა: 
`brew cleanup`

ყველაფრის წაშლა (ყველა გადმოწერილი ფაილის):
`brew cleanup --prune=all`

იმისათვის, რომ შემთხვევით საჭირო ფაილები არ წაშალოთ, დაიმახსოვრეთ განსხვავება: 

| **საქაღალდე**               | **დანიშნულება**                                              | **შეიძლება წაშლა?** |
| --------------------------- | ------------------------------------------------------------ | ------------------- |
| `~/Library/Caches/Homebrew` | **დროებითი** გადმოწერილი ფაილები (***Downloads***).          | **დიახ**            |
| `/opt/homebrew/Cellar`      | აქ არის **გაშლილი** და მომუშავე პროგრამები (***Formulae***). | **არა**             |
