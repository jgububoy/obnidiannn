## Caches & Download Directory
[01_3. homebrew - პაკეტების მენეჯერი](01_1.%20homebrew%20-%20პაკეტების%20მენეჯერი.md) 

Homebrew **ავტომატურად არ შლის** ძველ გადმოწერილ ფაილებს ინსტალაციის შემდეგ, რაც დროთა განმავლობაში დიდ ადგილს იკავებს დისკზე.

| **ბრძანება**               | **რას აკეთებს**                                                                                                                    |
| -------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `brew --cache`             | მისამართის მონახვა                                                                                                                 |
| `brew cleanup -n`          | გაჩვენებთ, რამდენი ადგილის გამოთავისუფლებაა შესაძლებელი (წაშლის გარეშე).                                                           |
| `brew cleanup`             | წაშლის ყველა ***ძველ ვერსიას*** და დროებით ფაილს ქეშიდან.                                                                          |
| `rm -rf $(brew --cache)`   | ***მთლიანად ასუფთავებს*** გადმოწერილ საინსტალაციოებს ( `~/Library/Caches/` -ში , მთლიანად შლის საქაღალდე `homebrew` -ს ).          |
| `brew cleanup --prune=all` | `~/Library/Caches/Homebrew` საქაღალდეში წაშლის ***Download*** და ***caches*** საქაღალდეებში ჩაყრილ ფაილებს ( **საინსტალაციოებს** ) |

ეს ფაილები ინახება იმისთვის, რომ თუ მომავალში იგივე პროგრამის ხელახალი ინსტალაცია დაგჭირდებათ, Homebrew-მ ის აღარ გადმოწეროს ინტერნეტიდან და დაზოგოს დრო.


მას შემდეგ, რაც პროგრამა დაინსტალირდება, Homebrew მას გადაიტანს თავის სამუშაო გარემოში (ჩვეულებრივ `/opt/homebrew/Cellar` ან `/opt/homebrew/Caskroom`), ხოლო ორიგინალ გადმოწერილ არქივს (`.tar.gz` ან `.dmg`) ტოვებს ქეშში.

## 🐧 Linux-თან შედარება

Homebrew ასრულებს იმავე როლს, რასაც პოპულარული მენეჯერები Linux დისტრიბუტივებში.

|**ფუნქცია**|**Homebrew (macOS)**|**APT (Ubuntu)**|**Pacman (Arch)**|
|---|---|---|---|
|**ინსტალაცია**|`brew install`|`sudo apt install`|`sudo pacman -S`|
|**წაშლა**|`brew uninstall`|`sudo apt remove`|`sudo pacman -R`|
|**განახლება**|`brew upgrade`|`sudo apt upgrade`|`sudo pacman -Syu`|

#### 💡 რა ხდის Homebrew-ს განსაკუთრებულს?

- **Root წვდომა:** ინსტალაციისთვის ხშირად არ სჭირდება `sudo`.
- **Cask სისტემა:** შეუძლია სრულფასოვანი GUI აპლიკაციების მართვა.
- **Git ბაზა:** მთელი სისტემა ეყრდნობა Git-ს, რაც მას მოქნილს ხდის.
