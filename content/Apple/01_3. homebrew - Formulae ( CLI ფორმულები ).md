# 01_3. homebrew - Formulae ( CLI ფორმულები )

homebrew  მართავს **ორი ტიპის** პროგრამას:
[Используем Homebrew - YouTube](https://www.youtube.com/watch?v=3JrLhReusrY) 

1. **Formulae (ფორმულები):** CLI ხელსაწყოები და ბიბლიოთეკები (`git`, `python`, `node`).
2. **Casks (კასკები):** გრაფიკული აპლიკაციები (`google-chrome`, `visual-studio-code`, `spotify`).

### **Formulae (ფორმულები):**

 ძირითადი მახასიათებლები:

- **რა არის ფორმულა?** – ეს არის პროგრამა, რომელიც ჩამოიტვირთება **საწყისი კოდის** (Source Code) სახით.
- **ინსტალაციის პროცესი:** პროგრამა ან პირდაპირ ეშვება, ან იკრიბება (Compile/Build) უშუალოდ თქვენს ლოკალურ კომპიუტერზე.
- **ღიაობა:** როგორც წესი, ფორმულები არის **Open Source** (ღია კოდის მქონე) პროგრამები. ეს ნიშნავს, რომ მათი საწყისი კოდი საჯაროდ ხელმისაწვდომია ნებისმიერი მომხმარებლისთვის.
