# homebrew - cask

***homebrew***  მართავს **ორი ტიპის** პროგრამას:
[Homebrew: Cask'и - YouTube](https://www.youtube.com/watch?v=qbVGnfci-FU) 
[Homebrew: The Package Manager for Everywhere](https://brew.sh/) 

1. **Formulae (ფორმულები):** CLI ხელსაწყოები და ბიბლიოთეკები (`git`, `python`, `node`).
2. **Casks (კასკები):** გრაფიკული აპლიკაციები (`google-chrome`, `visual-studio-code`, `spotify`).

### 1. რა არის Cask?

**Cask** (ქართულად: კასრი/კასკი) გამოიყენება **პროპრიეტარული** ( არაღია/კომერციული ) პროგრამული უზრუნველყოფის დასაყენებლად.

- **რა არის პროპრიეტარული პროგრამა?** – ეს არის პროგრამა, რომელიც მოწოდებულია საწყისი კოდის გარეშე, უკვე გამზადებული „ანაბეჭდის“ სახით (მაგალითად: **Adobe Photoshop**).
    
- **როგორ ამოვიცნოთ?** – macOS-ში ასეთი პროგრამები ჩვეულებრივ ვრცელდება **.dmg** ფორმატის ფაილებით.
    
- **ინსტალაციის პრინციპი:** ნაცვლად კოდის კომპილაციისა, Cask-ი ავტომატურად აკეთებს იმას, რასაც თქვენ ხელით გააკეთებდით: ტვირთავს `.dmg` ფაილს, ხსნის მას და მასში არსებულ **.app** ფაილს (პროგრამის გამზადებულ პაკეტს) გადაიტანს `Applications` (აპლიკაციების) საქაღალდეში.


„***დაინსტალირებული პროგრამების ზოოპარკი***“ – ეს გულისხმობს თქვენს კომპიუტერზე არსებულ უამრავ სხვადასხვა აპლიკაციას. Homebrew-ს ერთ-ერთი მთავარი უპირატესობა ის არის, რომ მას შეუძლია **ერთი ბრძანებით** განაახლოს ყველა ეს პროგრამა (როგორც ფორმულები, ისე კასკები).

---

> **შენიშვნა:** macOS-ში `.app` ფაილი სინამდვილეში არის საქაღალდე, რომელიც შეიცავს პროგრამის გამშვებ ფაილებსა და ყველა საჭირო რესურსს ერთად.



`brew upgrade` - ყველა ***დაინსტალირებული პაკეტის*** განახლება. ***მხოლოდ Formulae - ები***. ანუ განაახლებს მხოლოდ open source პროგრამებს. 
`brew upgrade --cask` - ეს ჩანაწერიც არ განაახლებს. 

`brew upgrade -cask (პროგრამის სახელი)` - ასეთი ჩანაწერი განაახლებს, ოღონდ ყველას სახელი უნდა ჩამოწერო, რაც არაკომფორტულია.
ამიტომ ყველა cask -ის განახლების
***ლაიფხაკი***:

```bash
brew upgrade --cask $(brew list --cask)
```
ანუ ტერმინალში გადავეცით სია, რომელიც უნდა განაახლოს.
