# desktop icons on Macbook

desktop-ზე ფაილების დამალვისთვის  სხვადასხვა ქარხნული და კუსტარული მეთოდები: 
## System Settings ფუნქციებიდან:  
იმალება ფაილები ეკრანზე: 
1. System Settings / Desktop&Dock / და მოსაპტიჩკია: show items on desktop. 
2. click wallpaper to show desktop : Always  ან only in Stage Manager

## Terminal :
 ეს საშუალებას გაძლევს, ფაილი გააქრო ისე, რომ "დამალული ფაილების ჩვენების" რეჟიმშიც კი არ ჩანდეს ბუნდოვნად.
### მეთოდი 1: სრული დამალვა (Terminal)

ეს მეთოდი საუკეთესოა, თუ გინდა, რომ დესკტოპი სუფთად გამოიყურებოდეს:

1. გახსენი **Terminal** (დააჭირე `Command + Space` და ჩაწერე Terminal).
2. ჩაწერე შემდეგი ბრძანება და ბოლოში აუცილებლად დასვი **Space (გამოტოვება)**: `chflags hidden`
3. დესკტოპიდან მაუსით გადმოათრიე და ჩააგდე ის ფაილი (ან საქაღალდე) პირდაპირ ტერმინალის ფანჯარაში.
4. დააჭირე **Enter**.

ფაილი მაშინვე გაქრება დესკტოპიდან.

**როგორ დავაბრუნოთ?** თუ ფაილის გამოჩენა დაგჭირდება, ტერმინალში ჩაწერე იგივე, ოღონდ `nohidden`: `chflags nohidden [ჩააგდე ფაილი აქ]`

### მეთოდი 2: დესკტოპის ყველა ხატულას დამალვა

თუ ბევრი ფაილი გაქვს და უბრალოდ გინდა, რომ დესკტოპი დროებით "გასუფთავდეს" (მაგალითად, ვინმეს ეკრანს როცა აჩვენებ):

1. ტერმინალში ჩაწერე ეს ბრძანება: `defaults write com.apple.finder CreateDesktop false`
2. შემდეგ დააჭირე Enter და ჩაწერე: `killall Finder`

დესკტოპი გახდება სრულიად ცარიელი. ფაილები არ წაიშლება, ისინი ისევ იქნება `Desktop` საქაღალდეში (რომელსაც Finder-იდან გახსნი), უბრალოდ ეკრანზე არ გამოჩნდება.

**უკან დასაბრუნებლად:** ჩაწერე იგივე ბრძანება, ოღონდ `false`-ს ნაცვლად მიუთითე `true` და ისევ დაარეფრეშე Finder (`killall Finder`).

### მეთოდი 3: "Stacks" (დახარისხება)

თუ დამალვა იმიტომ გინდა, რომ დესკტოპზე არეულობაა, macOS-ს აქვს ფუნქცია **Stacks**, რომელიც ფაილებს ტიპების მიხედვით აჯგუფებს და ერთ პატარა გროვად აქცევს.

- დააჭირე დესკტოპზე მარჯვენა ღილაკს და აირჩიე **Use Stacks**.

რომელიმე კონკრეტული ფაილის დამალვა გინდა თუ უბრალოდ ეკრანზე წესრიგის დამყარება?
