# macbook -ზე არ მუშაობს NTFS


## კითხვა 1 : სხვა ყველა ფლეშკა ჩანს. არ ჩანს საერთოდ მხოლოდ ntfs ფლეშკები. 

თუ სხვა ფლეშკები (მაგალითად, FAT32 ან exFAT ფორმატის) უპრობლემოდ ჩანს, ხოლო **მხოლოდ NTFS** ფლეშკები საერთოდ არ ფიგურირებს Disk Utility-ში, ეს ნიშნავს, რომ პრობლემა პროგრამულ დონეზეა, თუმცა macOS-ის სტანდარტული ქცევისთვის ეს მაინც უჩვეულოა (წესით, წაკითხვის რეჟიმში მაინც უნდა აჩვენებდეს).

აი, რა უნდა გავაკეთოთ ასეთ შემთხვევაში:

#### 1. შეამოწმეთ System Information (ტექნიკური დონე)

ეს დაგვიდასტურებს, საერთოდ აღიქვამს თუ არა "რკინა" ფლეშკას:

1. დააჭირეთ Apple ლოგოს () მარცხენა კუთხეში.
    
2. გეჭიროთ **Option** ღილაკი კლავიატურაზე და დააჭირეთ **System Information...**.
    
3. მარცხენა სიაში იპოვეთ **USB**.
    
4. ნახეთ, ჩანს თუ არა აქ თქვენი ფლეშკის სახელი.
    
    - **თუ აქ ჩანს:** ე.ი. მაკი ხედავს მოწყობილობას, მაგრამ macOS ვერ ახდენს მის "Mount"-ს (მიერთებას) NTFS ფორმატის გამო.
        
    - **თუ აქაც არ ჩანს:** მაშინ ფლეშკას ან გადამყვანს აქვს დენის მიწოდების ან კონტაქტის პრობლემა (M-ჩიპები ძალიან მგრძნობიარეა NTFS მოწყობილობების კვებაზე).
        

---

#### 2. რატომ შეიძლება ბლოკავდეს სისტემა?

ხშირად, თუ Windows-ზე ფლეშკა "არასწორად" იქნა ამოღებული (Eject-ის გარეშე), NTFS სისტემაში რჩება ე.წ. **"Dirty Bit"**. macOS-ს ასეთი ფლეშკების მიერთება უსაფრთხოების გამო უჭირს.

**გამოსავალი:**

1. შეაერთეთ ფლეშკა Windows კომპიუტერზე.
    
2. გახსენით Command Prompt (Admin) და ჩაწერეთ: `chkdsk E: /f` (სადაც E თქვენი ფლეშკის ასოა).
    
3. ამის შემდეგ გააკეთეთ **Safely Remove Hardware** და სცადეთ ისევ Mac-ზე.
    

---

#### 3. გამოიყენეთ მესამე მხარის უფასო დამხმარე

ვინაიდან Apple Silicon-ს (M1/M2/M3) NTFS-ის სრული მხარდაჭერა არ აქვს, სცადეთ პროგრამა **Mounty for Mac**. ის ეხმარება სისტემას NTFS დისკების იდენტიფიცირებაში და მათ მიერთებაში.

- გადმოწერეთ [Mounty](https://mounty.app/).
    
- ჩართეთ და ნახეთ, ხომ არ ამოაგდებს შეტყობინებას ფლეშკის აღმოჩენის შესახებ.
    

---

#### 4. ტერმინალით "ძალდატანებითი" დანახვა

გახსენით **Terminal** და ჩაწერეთ შემდეგი ბრძანება: `diskutil list`

ეს ბრძანება აჩვენებს ყველა მიერთებულ დისკს, მათ შორის მათაც, რომლებსაც სისტემა "ვერ ხსნის". თუ სიაში იპოვით თქვენს ფლეშკას (მაგალითად, როგორც `/dev/disk4`), მაშინ პრობლემა მხოლოდ ფაილური სისტემის წაკითხვაა.

---

#### 💡 საუკეთესო რჩევა (გრძელვადიანი)

თუ თქვენ გჭირდებათ, რომ ფლეშკამ **ორივე სისტემაზე** (Mac და Windows) იმუშაოს ყოველგვარი პროგრამების და პრობლემების გარეშე:

- დააფორმატეთ ფლეშკა **exFAT** სისტემაში.
    
- exFAT არის "უნივერსალური ენა", რომელსაც Mac-იც და PC-ც მშობლიურად, მაღალ სიჩქარეზე და შეზღუდვების გარეშე კითხულობს/წერს.


## კითხვა 2 :  `diskutil list` გავუშვი  და სისტემამ გაჭედა, როგორც disk util-ის გაშვებისას.  ტერმინალში გაშვებული ბრძანება ჯერ კიდევ ფიქრობს

ეს ძალიან ნაცნობი სიტუაციაა. ის ფაქტი, რომ `diskutil list` და **Disk Utility** ჭედავს, ადასტურებს, რომ macOS ცდილობს ფლეშკის "დამონტაჟებას" (Mount), მაგრამ NTFS-ის ფაილურ სისტემაში არსებული შეცდომის ან დრაივერების კონფლიქტის გამო პროცესი **"Infinite Loop"**-ში (დაუსრულებელ ციკლში) ვარდება.

სისტემა ელოდება პასუხს ფლეშკისგან, რომელსაც ვერ იღებს, და ამის გამო მთლიანი Disk Management სერვისი იყინება.

აი, როგორ უნდა გამოასწოროთ ეს:

#### 1. გათიშეთ გაჭედილი პროცესი

სანამ ფლეშკას არ გამოაძრობთ, ტერმინალი და Disk Utility არ "გაიღვიძებს".

- **გამოაძრეთ ფლეშკა.**
    
- ტერმინალში დააჭირეთ `Control + C`, რომ გააჩეროთ ბრძანება.
    
- თუ Disk Utility მაინც გაჭედილია, დააჭირეთ `Command + Option + Escape` და გათიშეთ (Force Quit).
    

#### 2. მთავარი პრობლემა: "Dirty FS"

როგორც წესი, ეს ხდება მაშინ, როცა NTFS ფლეშკა Windows-იდან ისე გამოაძრეს, რომ მონაცემების ჩაწერა ბოლომდე არ იყო დასრულებული. Windows-ი ამ დროს ფლეშკაზე ტოვებს ნიშნულს, რომ "სისტემა დაზიანებულია". Mac-ი ამ ნიშნულს ხედავს, ცდილობს მის გამოსწორებას/შემოწმებას და ამ დროს იჭედება.

**გამოსავალი:** თუ გაქვთ წვდომა Windows კომპიუტერთან:

1. შეაერთეთ ფლეშკა Windows-ზე.
    
2. გახსენით **This PC**, დააჭირეთ მარჯვენა ღილაკით ფლეშკას -> **Properties** -> **Tools** -> **Check** (Error checking).
    
3. შემოწმების შემდეგ აუცილებლად დააჭირეთ **"Safely Remove Hardware"** (საათის გვერდით) და ისე გამოაძრეთ.
    

#### 3. თუ Windows არ გაქვთ (გამოსწორება Mac-იდან)

უნდა ვცადოთ ფლეშკის დაფორმატება მანამ, სანამ სისტემა მის "წაკითხვას" დაიწყებს.

1. გამოაძრეთ ფლეშკა.
    
2. ტერმინალში ჩაწერეთ ეს ბრძანება, მაგრამ **ჯერ არ დააჭიროთ Enter-ს**: `diskutil eraseDisk ExFAT NEWDISK /dev/disk4` _(შენიშვნა: `/dev/disk4`-ის ნაცვლად შეიძლება სხვა ციფრი იყოს საჭირო, ამიტომ ეს გზა სარისკოა, თუ ზუსტად არ ვიცით ნომერი)._
    

**უფრო უსაფრთხო გზა:**

1. გახსენით **Disk Utility**.
    
2. **მხოლოდ ამის შემდეგ** შეაერთეთ ფლეშკა.
    
3. წამიერად, სანამ სისტემა გაჭედავს, ფლეშკა შეიძლება გამოჩნდეს სიაში. თუ მოასწრებთ, დააჭირეთ მასზე და მაშინვე აირჩიეთ **Erase**.
    

---

#### 4. რატომ ჭედავს Apple Silicon-ი?

Apple Silicon-ის macOS-ს აქვს ახალი ტიპის დრაივერები (Filesystem in Userspace - FUSE). როცა NTFS ფლეშკას აერთებთ, სისტემა უშვებს პროცესს სახელით `fsck_ntfs`. სწორედ ეს პროცესი ჭამს პროცესორის რესურსს და ყინავს ინტერფეისს.

**შეგიძლიათ სცადოთ ამ პროცესის მოკვლა:**

1. შეაერთეთ ფლეშკა.
    
2. გახსენით **Activity Monitor**.
    
3. ძებნაში ჩაწერეთ `fsck`.
    
4. თუ იპოვით `fsck_ntfs`, მონიშნეთ და დააჭირეთ **X**-ს (Force Quit). _ამის შემდეგ Disk Utility-მ წამიერად უნდა "ამოისუნთქოს" და დაგანახოთ ფლეშკა._
