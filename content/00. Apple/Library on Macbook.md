# Library on Macbook

macOS-ში **სამი განსხვავებული Library (ბიბლიოთეკა)**`Library` არსებობს:

მოდი, დავაზუსტოთ, რა განსხვავებაა მათ შორის, რომ შემთხვევით ზედმეტი არ წაგეშალოს:

### 1. Root Library (`/Library`) — რასაც შენ ხედავ

ეს არის ბიბლიოთეკა, რომელიც საერთოა კომპიუტერის ყველა მომხმარებლისთვის.

- **რა დევს აქ:** დრაივერები, სისტემური შრიფტები (Fonts), აპლიკაციების საერთო რესურსები (როგორც შენი ნანახი Apple Loops) და პარამეტრები, რომლებიც ყველას ეხება.
    
- **შეიძლება წაშლა?** **ნაწილობრივ.** მთლიანი საქაღალდის წაშლა სისტემას დააზიანებს. კონკრეტული ქვე-საქაღალდეების წაშლა (მაგალითად, `Audio > Apple Loops`) უსაფრთხოა, მაგრამ სხვა რამეებს (მაგალითად, `CoreServices` ან `Preferences`) არ უნდა შეეხო.
    

### 2. System Library (`/System/Library`)

ეს არის macOS-ის "გული".

- **რა დევს აქ:** ფაილები, რომელთა გარეშეც კომპიუტერი საერთოდ არ ჩაირთვება. თანამედროვე macOS-ზე ეს ნაწილი "Read-Only"-ა, ანუ სისტემა ფიზიკურად არ მოგცემს აქედან რამის წაშლის უფლებას.
    

### 3. User Library (`~/Library`)

ეს არის შენი პირადი ბიბლიოთეკა, რომელიც დამალულია.

- **რა დევს აქ:** შენი აპლიკაციების პარამეტრები (Cache), ბრაუზერის ისტორია, მეილის მონაცემები და ა.შ.
    
- **შეიძლება წაშლა?** აქედან რამის წაშლით სისტემას არაფერი მოუვა, მაგრამ შეიძლება აპლიკაციებმა "დაკარგონ მეხსიერება" (მაგ. თავიდან მოგთხოვონ პაროლის შეყვანა).
    

### შეჯამება: წავშალო თუ არა?

თუ შენი მიზანი **ადგილის გამოთავისუფლებაა**:

1. **Apple Loops-ის წაშლა:** აბსოლუტურად უსაფრთხოა. სისტემას არაფერი დაემართება, უბრალოდ GarageBand-ში ხმები აღარ იქნება.
    
2. **სხვა საქაღალდეები Library-ში:**`Library` ძალიან ფრთხილად იყავი. თუ ზუსტად არ იცი, რა არის (მაგალითად: `Application Support`, `Frameworks`, `LaunchDaemons`), **არ წაშალო**. ამან შეიძლება გამოიწვიოს აპლიკაციების გათიშვა ან სისტემის არასტაბილურობა.
    

**მარტივი წესი:** თუ ფაილური მენეჯერი წაშლისას ადმინისტრატორის პაროლს გთხოვს (როგორც ეს `/Library`-ს შემთხვევაში ხდება), ეს ნიშნავს, რომ იმას შლი, რაც მხოლოდ "შენი" არაა და სისტემისთვის მნიშვნელოვანია.

ადგილის გამოთავისუფლება გინდა და მაგიტომ ეძებ დიდ ფაილებს, თუ უბრალოდ სისტემის ოპტიმიზაციას აკეთებ?
